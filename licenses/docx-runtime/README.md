# DOCX导出依赖文字保留

docx 9.14.0在构建时编入宿主，不要求用户安装Node、Word或LibreOffice。provenance.json列出其已声明运行依赖闭包的17个组件、供应包声明的许可和17份实际保留文件摘要；类型包不进入运行代码。

文件从本项目锁定npm依赖按原始字节复制，非重新编写许可。hash.js 1.1.7将完整MIT版权与授权正文放在README内，因此保留完整README；见[原始版本](https://github.com/indutny/hash.js/blob/v1.1.7/README.md)。收集脚本遇到无独立许可也无完整README授权正文的组件会失败，不用包名或一个SPDX字符串代替授权正文。

JSZip保留原始双许可文字，本项目按其MIT许可路径使用；pako供应包声明MIT与Zlib均保留。具体条件以各保留原文为准，本项目MIT不重新授权这些组件或用户小说。此单项清单和摘要检查不代替整个应用的完整分发审计。
