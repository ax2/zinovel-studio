# ZiNovel Studio 技术预览使用说明

本说明对应 alpha.4 开发候选；已公开版本请以 GitHub Release 标签为准。当前是可手工写作、局部 AI 编辑和恢复审阅的预览平台，人物世界卡、大纲看板、地图及多格式出版仍在开发。

## 安装与开始写作

从 [官方项目 Releases](https://github.com/ax2/zinovel-studio/releases) 下载 Windows x64 `*-setup.exe`。不需要预装 Node 或 pnpm。当前未代码签名；附件 SHA256SUMS.txt 可以核对文件字节，不能替代发布者签名。安装后从开始菜单打开 ZiNovel Studio。

进入书库，点击“新建作品”，填写题名，再新建章节。正文可以直接手工输入，自动保存状态会显示在编辑区；Ctrl+S 可立即保存。没有模型 Key 也能写作。标题、卷章顺序和作品状态可通过相应管理入口调整；标题不是文件 ID，改名不会重新编号所有正文文件。

正文保存失败或发现外部改动时，先处理界面提示。冲突窗口保留原稿、磁盘稿和当前稿，可核对后明确接受；不要把“编辑中”或错误提示当成已保存。历史入口可以查看和恢复旧稿。接受 AI 修改后可一次撤销，重做恢复本次接受内容。

## 配置模型与费用

主导航打开“模型设置”，填写所使用服务的 API 地址、账号支持的模型名称和 Key。远端地址要求 HTTPS；本机测试服务可用 localhost HTTP。Key 在本机通过 Windows 系统安全存储加密，保存后不会读回到输入框；留空表示保留原值。

按自己的需要设置模型步骤、章节上下文、每步输出和 Token 阈值。可以填写当前模型的 CNY/USD 四类每百万 Token 单价，启用费用阈值；价格由作者提供，应用不保证它与服务商最新账单一致。修改模型或地址会清空旧价格。旧任务保留开始时的预算，调整设置后需明确创建新任务或重试。

生成前的预估只覆盖作者材料与输出上限；完整系统消息和工具会在实际发送前另行检查。未知用量不当作零。费用限制按已知金额与下一次估算拦截，单次调用仍可能超过估算，不是服务商账单的硬封顶。

## 局部 AI 写作与审阅

选中一段正文，在创作参考中的“写作助理”选择创作方法并填写要求，然后点击“生成候选”。当前模型会接收该章节正文、选区、要求及对应方法说明；使用云模型前应确认这些内容适合发给所选服务。不会发送整部书作为默认输入。

候选先进入审阅，不直接改正文。可以展开“逐块审阅”，分别采用修改或保留原文，也可以手工改候选文本；手工修改会合并当前选择并重新计算差异。大输入可能合为较大修改块，界面明确提示。点击最终“接受候选”才写入正文并保留历史。

如果暂时不想采用，可点击“保存审阅草稿”。显示“已保存”后，关闭或重启应用，再从“写作任务记录”打开该任务继续审阅。原模型候选、保存的草稿及最终接受文本各自保留；未点击保存的调整可能随关闭丢失。保存草稿不修改正式稿。

生成期间继续编辑了正文，旧候选不会静默覆盖新稿；先保留候选，核对当前内容后再开启新任务。多候选并排比较和另存小说分支尚未提供。

## 取消、中断与恢复

“取消生成”会停止任务。任务记录显示取消、失败、中断、待审阅或已接受的实际状态。已经落盘的可见流式片段可以在重启后参考，但未完成片段不能直接按完整候选接受；强制结束进程仍可能丢失尚未落盘的尾部。

应用不会在启动时自动重发模型请求。需要继续时打开目标章节，检查当前选区，再明确重试；会创建新任务，旧记录保留。旧版本未绑定书章的任务只读显示，应用不会猜测其归属并写进某部书。

## 导入、备份和移动数据

导入文本时先查看编码和章边界预览，再创建新书；原文件不被修改。当前支持文本/Markdown 路线及常见中文编码。EPUB/DOCX/PDF 与网站正式发布尚未验收，不能视为已经支持。

整书备份会复制作品目录并写校验清单，恢复创建一个新的作品 ID，不覆盖唯一原书。备份目的地应位于作品目录之外，重要稿件另存其他磁盘。当前恢复限制为 512 MiB，超过范围的恢复会明确拒绝。

默认作品位于 `%APPDATA%\ZiNovel Studio\library`。AI 任务和审阅草稿位于同一应用数据根目录下的 `tasks`，**不包含在当前整书备份中**。因此整书恢复不等于完整工作区迁移；任务跨书重新绑定与工作区备份能力尚待实现。模型设置中的加密 Key 也不能保证跨用户或跨设备可用。

## 更新范围

版本标签会自动触发构建、安装/运行及升级检查后发布 EXE；应用自身暂无自动更新。alpha.4 的指定升级路径是 alpha.3 → alpha.4，同用户、同架构，升级前仍应保存并备份作品。卸载测试确认保留测试稿件，但不应把卸载当作备份策略。

问题反馈请提供应用版本、操作步骤、保存/任务状态和可脱敏的截图；不要公开 Key、完整私人稿件、系统安全存储内容或账号凭据。
