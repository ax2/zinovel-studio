# ZiNovel Studio 技术预览使用说明

最新公开版为alpha.33，包含Windows安装EXE，独立CI已完成安装/重装/卸载及公开alpha.3、alpha.31升级；公开附件已下载并核对hash。图像工作室支持明确复评已有候选，并修正进程中断恢复验证。主线alpha.34加入人物形象版本与明确定妆选择，目前仅源码/桌面操作验收通过，安装与升级待完成。所有版本继续使用官方DeepSeek Harness；稳定版和商店资格仍关闭。alpha.32未发布，下载入口以README为准。

## 安装与开始写作

alpha.26修复窄窗口展开创作参考后阅读正文被挤到屏幕外的问题。模型等待或服务不可达时仍可手工保存；切换作品会取消原作品进行中的生成任务，不自动应用候选。alpha.27已交付增量备份及选版恢复界面，原有完整目录副本方式仍可用。

PDF排版已在alpha.22公开。在支持的版本中，进入“导出与发布”，选择冻结副本，将格式切换为“PDF 排版副本”，调整纸张、字体类别、字号、行距、边距及段落分页后导出。结果是新目录中的book.pdf和摘要清单，不会覆盖当前书稿或既有导出；取消目录选择不会产生PDF。暂为纯文字，每次内容上限8 MiB，字体依赖本机回退，请检查罕见字与分页。

alpha.24新增“DOCX 可编辑副本”：同样从已保存的冻结副本导出，默认Letter纸张，可选A4/A5和正文排版。结果为book.docx和摘要清单，保留真实段落、章节标题和页码，可以在Word等软件手工修改。生成不要求本机安装Word；打开软件会自行匹配字体和分页，请检查全文。DOCX/PDF当前均为纯文字，每次内容上限8MiB，DOCX另有20,000段和100,000显式换行保护；不是格式导入或自动同步回书稿。

alpha.25新增带图HTML：在“导出与发布”展开图像选择，添加封面或已选章节的章首/章尾插图，填写公开替代文字，可补图注和署名。确认图片版本后创建副本；替换或回收原图不会改变旧副本。未填完的图像表单可暂存，但不能创建副本。导出时保留整个目录及images子目录，才能离线显示图像。

从 [官方项目 Releases](https://github.com/ax2/zinovel-studio/releases) 下载 Windows x64 `*-setup.exe`。不需要预装 Node 或 pnpm。当前未代码签名；附件 SHA256SUMS.txt 可以核对文件字节，不能替代发布者签名。安装后从开始菜单打开 ZiNovel Studio。

进入书库，点击“新建作品”，填写题名，再新建章节。正文可以直接手工输入，自动保存状态会显示在编辑区；Ctrl+S 可立即保存。没有模型 Key 也能写作。标题、卷章顺序和作品状态可通过相应管理入口调整；标题不是文件 ID，改名不会重新编号所有正文文件。

正文保存失败或发现外部改动时，先处理界面提示。冲突窗口保留原稿、磁盘稿和当前稿，可核对后明确接受；不要把“编辑中”或错误提示当成已保存。历史入口可以查看和恢复旧稿。接受 AI 修改后可一次撤销，重做恢复本次接受内容。

## 配置模型与费用

alpha.30已交付“管理多个模型与能力”。明确确认迁移后，可新增各自拥有服务、模型、Key和预算的配置，分别选择文字与图像服务。文字任务使用面板显示的配置；列表或路由在别处改变时，生成会先拒绝，请刷新选择并核对名称后再发。已开始任务和历史任务保留当时的配置名称、修订，切换服务不会改写历史任务。alpha.30只保存图像配置；alpha.31增加独立的AI图像工作室，仍需先明确确认服务支持的响应模式，不能把文字模型自动当图像模型。

首次迁移将原设置字节备份在应用私有目录，含系统加密旧Key；活动设置使用schema2指针。旧版不能读取新版模型设置，正文仍可手工使用。清除某配置Key不会清除迁移前备份。列表缺失时不会自动使用旧服务；界面可明确恢复迁移前的一份配置，但不会恢复迁移后新增、更改或删除的项目。损坏、未来格式和身份不符的文件拒绝覆盖，请先保留完整私有数据。不要公开设置文件或迁移备份。

主导航打开“模型设置”，填写所使用服务的 API 地址、账号支持的模型名称和 Key。远端地址要求 HTTPS；本机测试服务可用 localhost HTTP。Key 在本机通过 Windows 系统安全存储加密，保存后不会读回到输入框；留空表示保留原值。

按自己的需要设置模型步骤、章节上下文、每步输出和 Token 阈值。可以填写当前模型的 CNY/USD 四类每百万 Token 单价，启用费用阈值；价格由作者提供，应用不保证它与服务商最新账单一致。修改模型或地址会清空旧价格。旧任务保留开始时的预算，调整设置后需明确创建新任务或重试。

生成前的预估只覆盖作者材料与输出上限；完整系统消息和工具会在实际发送前另行检查。未知用量不当作零。费用限制按已知金额与下一次估算拦截，单次调用仍可能超过估算，不是服务商账单的硬封顶。

## 局部 AI 写作与审阅

选中一段正文，在创作参考中的“写作助理”选择创作方法并填写要求，然后点击“生成候选”。当前模型会接收该章节正文、选区、要求及对应方法说明；使用云模型前应确认这些内容适合发给所选服务。不会发送整部书作为默认输入。

候选先进入审阅，不直接改正文。可以展开“逐块审阅”，分别采用修改或保留原文，也可以手工改候选文本；手工修改会合并当前选择并重新计算差异。大输入可能合为较大修改块，界面明确提示。点击最终“接受候选”才写入正文并保留历史。

如果暂时不想采用，可点击“保存审阅草稿”。显示“已保存”后，关闭或重启应用，再从“写作任务记录”打开该任务继续审阅。原模型候选、保存的草稿及最终接受文本各自保留；未点击保存的调整可能随关闭丢失。保存草稿不修改正式稿。

生成期间继续编辑了正文，旧候选不会静默覆盖新稿；先保留候选，核对当前内容后再开启新任务。当前开发版可在任务详情比较本页其他同章候选，基线不同时只读对照；选择另一版后仍须审阅确认。批量候选生成和另存小说分支尚未提供。

## 取消、中断与恢复

“取消生成”会停止任务。任务记录显示取消、失败、中断、待审阅或已接受的实际状态。已经落盘的可见流式片段可以在重启后参考，但未完成片段不能直接按完整候选接受；强制结束进程仍可能丢失尚未落盘的尾部。

应用不会在启动时自动重发模型请求。需要继续时打开目标章节，检查当前选区，再明确重试；会创建新任务，旧记录保留。旧版本未绑定书章的任务只读显示，应用不会猜测其归属并写进某部书。

## 导入、备份和移动数据

导入文本时先查看编码和章边界预览，再创建新书；原文件不被修改。当前支持文本/Markdown 路线及常见中文编码。EPUB/DOCX/PDF 的导入与网站正式发布尚未验收；已实现的导出格式见下文。

整书备份会复制作品目录并写校验清单，恢复创建一个新的作品 ID，不覆盖唯一原书。alpha.26会拒绝备份到整个受管书库内部，包括原书、另一部作品和指向它们的目录别名；请选择书库外的目录，重要稿件另存其他磁盘。当前恢复限制为 512 MiB，超过范围的恢复会明确拒绝。

默认作品位于 `%APPDATA%\ZiNovel Studio\library`。AI 任务和审阅草稿位于同一应用数据根目录下的 `tasks`，**不包含在当前整书备份中**。因此整书恢复不等于完整工作区迁移；任务跨书重新绑定与工作区备份能力尚待实现。模型设置中的加密 Key 也不能保证跨用户或跨设备可用。

## 更新范围

版本标签会触发对应渠道的资格门禁、构建、安装/运行及升级检查。经过阶段验收的预览版会发布安装 EXE；稳定版仍需完整产品资格。当前下载版本以 README 核对记录为准；已验证从公开 alpha.3 同用户同架构覆盖升级，不能据此承诺所有历史版本均兼容。应用自身暂无自动更新。升级前应保存并备份作品；卸载保稿测试不替代备份。

问题反馈请提供应用版本、操作步骤、保存/任务状态和可脱敏的截图；不要公开 Key、完整私人稿件、系统安全存储内容或账号凭据。

## 创作资料（开发中）

在作品右侧“创作参考 → 资料卡”管理创意、人物、地点、世界规则、组织、物品、能力、现实资料、纲要、场景、主支线和伏笔计划。每类有独立字段，资料标题、别名、字段和笔记均可搜索。选“作者已确认设定”仍不表示正文已证实；实际正文事实、伏笔埋设与回收需要另外绑定证据。

组织卡记录制度、资源和代价；物品卡记录用途、限制、损毁和流转计划；能力卡记录触发、消耗、反制及上限。三者都可关联多章，并通过正文证据追溯实际发生的使用或变化。

现实资料记录来源、摘录、时间地域、争议和虚构改编边界。“事实（作者已核对）/传闻或争议/明确虚构”等性质由作者手工选择，程序不据此声称已经查证。AI 可以整理已有内容，但不能改性质标记或核对记录；这两个字段在候选审阅中只读，需在原卡修改。当前资料 Agent 没有外部网络检索工具，不会自动打开来源网址。

编辑后点击“保存资料”；未保存调整只暂存在本机，重新打开同一资料可找回，不计入作品备份。外部修改造成冲突时当前输入仍保留，“重新读取（放弃调整）”明确丢弃本地暂存后读取磁盘版本。资料回收站可恢复，历史内容先载入草稿再保存为新版本。导出资料输出已保存版本的 Markdown。

整书备份包含已保存的资料、资料历史及书内章节引用；恢复为新作品后引用仍有效。应用级 AI 任务、审阅草稿和本机未保存资料草稿不在整书备份范围内。

### 绑定正文证据

保存资料后，在正文选一段已保存内容，展开资料中的“添加正文证据”。填写说明、故事时间、认知范围和需要的关联资料，再“绑定当前选区为证据”。伏笔的计划仍在字段中，实际埋设、强化、回收分别记录证据。人物关系和人物/读者知情分开记录，旧事件不会被新事件覆盖。

当前章保存新版本后，旧证据自动提示待复核；外部或其他章修改可点“重新检查证据”。关联设定变化会显示绑定版本与当前版本，旧记录没有关联版本时明确提示未核对。原始引文保留，选择已保存范围后才能重新确认当前正文和关联资料。停用证据不会删除历史。

点击“定位正文证据”打开来源章并匹配当前编辑内容；唯一匹配会选择原始引文，缺失或重复匹配会提示，不随意选择位置，也不会将跳转视为重新确认。全书证据矩阵仍在开发。

### AI 参考资料

在“写作工具 → 本次参考资料”明确选择本书资料，可搜索并展开查看将发送的版本。最多 8 份，合计上限 2 万字符，超过时减少选择；程序不会悄悄截断。资料和当前章合计受到模型设置的上下文预算限制。人物计划、正文证据、待复核状态会保留各自标记。

若资料在预览后发生修改，生成会在模型请求前拦截。点击“刷新资料快照”核对新版后再生成。任务记录中的“当时的参考资料”是历史快照，后续编辑和重启不会改变。重新生成/重试使用当前明确选择的资料。读取资料不会自动修改人物卡或正式正文。

### AI 完善资料（已包含在公开 alpha.8）

先保存一份有标题的资料，在卡片下展开“AI 完善这份资料”，选择创作方法并填写修改要求。可先估算费用，也可明确选择其他参考资料。生成结果在独立语义表单中与原设定对照，只能修改标题、类型字段和笔记；类型、章节关联、作者确认状态与正文证据保留。

“保存资料审阅草稿”只保存候选调整，允许暂时空标题；关闭重启后从“这份资料的 AI 任务”继续。明确接受时才校验完整字段并检查资料版本，空标题或过期基线不会写入。接受后的任务只读，旧资料在历史中。接受中断时程序只核对回执，不自动重跑模型；状态不明确时可在任务中重新核对。全局任务记录也可查看资料任务，但正文接受入口不会应用资料提案。

### 场景看板与章纲（已包含在公开 alpha.8）

先在资料卡新建“场景”，填写目标、阻碍、人物选择和结果。在正文工具栏打开“场景编排”，未安排的场景放在第一列。拖到另一张卡之前或目标列末尾可改变位置；也可用“移动到”菜单跨章安排，或用上移/下移按钮（支持键盘）调整顺序。

切换“章纲”查看相同顺序下的视角、地点、时间及场景字段；“显示章节”适合窄窗或只看某章。字段摘要超过 240 字符时省略，点击“编辑场景完整资料”打开原卡片。编辑保存后重新打开或刷新规划显示新版。规划位置与资料的“关联章节”参考链接不同，移动不改链接、不重排正文，也不把场景计划当成已发生事实。

删除章节后原场景仍可见，并可移至有效章节；删除场景后原位置保留，到资料回收站恢复即可。外部更改规划后，过期移动会被拒绝，请刷新再操作。已保存的位置与历史包含在整书备份中；目前没有规划历史恢复界面。

## 试写实验室（alpha.9）

在正文工具栏打开“试写实验室”，建立一个实验组，描述固定场景任务，并按需关联最多八份本书创意、人物或场景资料。建立时冻结来源版本，后续资料变化会提示待核对。实验组的场景任务固定，新的场景另建实验组。

创建空白样稿并填写视角、声音、人物行动、阻碍与读者承诺，直接编辑试写正文。“保存试写”或 Ctrl+S 写入作品；“复制为独立分支”保留原稿并新建另一份样稿，可尝试不同视角与声音。选择“对照样稿”查看两份完整文本；改回“不对照”继续编辑，原撤销栈保留。

尚未保存的正文和字段只暂存在本机，关闭后重新打开同一份样稿可恢复。暂时空标题也能恢复，但需要补全标题才能正式保存。若本机草稿空间不足，切换样稿和关闭会被阻止；先明确保存试写。不能恢复从未成功暂存、保存的进程崩溃前输入。

磁盘稿被其他编辑器更改时，保存会拒绝覆盖。使用“读取磁盘版本供对照”核对双方，再明确保留当前调整并以磁盘版本为基线，或者放弃本地调整后重读。保留本地调整后仍需按需手工合并、明确保存；旧磁盘版本会保留在历史中。回收站保留样稿身份，恢复后可继续编辑。

“选定这个版本”保存当时的稿件和作者理由；后续修改提示选定版本过时。试读反馈必须填写来源，反馈绑定归档时的稿件版本，后续改稿不会替换旧反馈对象。选择理由和反馈输入只有明确提交后才归档。

“建立新章节并打开”从当前已保存样稿建立一个新章，不覆盖现有首章；同一版本重复执行只打开原先建立的章节。可以随后通过章节目录排序移动位置。已保存的样稿、历史、来源、选择、反馈和转章回执进入整书备份；未保存的本机草稿不进入备份。

保存样稿后展开“AI 试写当前分支”，查看将发送的场景、样稿和关联资料快照，填写本次要求。可以先预估预算，再生成候选；预估本身不调用模型。生成期间仍可取消，结果只作为候选保存。审阅时逐块取舍或手改，明确保存审阅草稿可在重启后继续；“接受”只更新当前试写正文，不改作者填写的声音等字段，也不替换正式章节。

资料在预览后变更，需要刷新快照才可生成；样稿或场景在生成后被改过，旧候选会拒绝覆盖，请保留候选、核对新稿再生成。关闭或重启不会重试模型、自动接受候选。应用级 AI 任务与审阅草稿仍不在整书备份内。全局任务列表可查看试写记录，继续审阅需进入对应作品的试写实验室。

## 全书证据与关系图（alpha.10）

正文工具栏“全书证据”集中列出已经绑定正文引文的记录，可按说明/人物/引文查找，筛选事件、知情范围、有效状态与章节。世界记录、读者已知、所属人物已知分别呈现；计划字段不会自动变为已写事实。

每条记录可打开原资料，或查看正文依据并定位引文。外部改稿和关联设定变化会提示待复核；已停用、资料已删除及来源失联的记录保留可见。修订或复核仍在原资料中完成。资料损坏时界面会说明结果可能不完整。

故事时间保留原文，叙述章序单列；列表按资料及记录顺序分页，不推断故事先后。扫描期间编辑可能使不同记录对应不同读取时刻，点击刷新重新核对。秘密矩阵和角色时序工作台仍在开发。

切换“关系图”可查看人物及设定的关系事件。点击事件高亮连接，点击对象筛选它作为所属或关联方的全部记录；“取消对象聚焦”恢复范围。可以缩放或适合视图。选择事件后，可在表格核对这一条、打开原资料或定位正文依据；多次和相反关系不会自动合并成一个结论。

图最多展示 24 个对象/60 条完整事件，超出会说明数量；可缩小筛选或切回证据表格查看全部分页。已停用事件、已删除或失联对象仍可见。大样本全量核对可能需要数秒，扫描期间可继续保存正文。窄窗打开创作参考时暂收章节目录，关闭参考即可恢复。

alpha.11 开发版正在改进查询取消：改变筛选或关闭视图会停止旧扫描，后续查询继续核对当前内容。此改进尚未包含在 alpha.10 安装包，完整工作区迁移、秘密矩阵和大书性能仍在后续。

### 认知矩阵（alpha.11）

主分支新增“认知矩阵”：先创建命题、回已保存正文选择依据，再为读者/世界/指定人物记录明确状态。空格表示没有记录，不等于不知道；相反记录并存。保存不改正文，改稿或定义修改会显示待复核，重新绑定记录新依据并保留历史。编辑器和矩阵之间来回可保留本机草稿，关闭重启也可恢复；本机草稿不属于整书备份。该功能已包含在 alpha.11 预览安装版；旧认知整理、故事时间推演和后续当前状态选择仍需继续补齐。

### AI 认知参考（alpha.13）

正文、资料完善和试写的“本次参考资料”可切换“资料卡 / 认知事件 / 作者当前选择”，搜索并选择参考，展开预览核对将发送的内容。三个类型共用8条和2万文本字符限制。认知只带本条范围、人物、状态、命题含义和正文引文，不隐式附带命题作者真相或其他认知；选择原资料卡仍按整张卡发送。资料完善还须填写修改要求。

作者选择采用当时冻结事件。后来事件改变会使其待复核，不会自动跟随；人物相信或怀疑也不等于世界真相。预览后发生相关改动，估算/生成会在发出模型请求前拒绝；请刷新快照核对后明确发起。既有任务保留当时快照，候选仍需审阅接受。此增量已包含在公开alpha.13安装版，完成本机及CI安装/升级验证；不包含在alpha.12。

### 作者当前选择（alpha.12）

认知详情可明确采用某个当前有效事件。这个选择不会删去相反认知；正文、事件或定义变化后提示过期，重新绑定证据后仍须明确选择。可清除选择和查看冻结旧引文的历史。矩阵只在全书记录视图显示当前选择，不把它当作倒叙或某个故事时刻的最终状态。本功能已包含在alpha.12预览安装版。

### 旧认知整理（alpha.12）

先在矩阵为命题开始新记录，再展开“整理旧认知证据”，搜索带入旧记录，核对范围、人物、状态，绑定当前保存的正文选区。旧记录不改；来源改版拒绝旧草稿，需重新带入核对。新记录保留最初旧引文，可区分旧笔记修改、原事件变化和新记录修订。已进入alpha.12安装版，但不代表AI已自动理解整书认知。

### 保存状态与草稿清理

若认知已经保存但本机草稿清理失败，界面会明确说明，暂时阻止重复保存和关闭；恢复本机存储后重试清理即可，正式记录保留。恢复的草稿可能已有存档，可用“检查是否已保存”查看并找回当前存档，保留调整后再明确修订。新建前若本机草稿暂不能保存，请恢复存储后重试，不关闭当前窗口。不要用旧版继续编辑新版未保存草稿。

## 独立阅读预览

alpha.17已通过本机及标签CI实际安装并公开。工具栏“阅读预览”会先保存当前编辑稿，然后进入仅正文的分卷阅读窗口。目录可按卷/定稿筛选，字号、行距、主题和390px手机宽度可调；该宽度为桌面模拟。阅读进度按作品保存在本机，只有正文hash一致才恢复段落；正文变化或章删除会提示，坏记录不会静默覆盖，可明确重置或重试保存。进度不在作品备份内。返回编辑后仍是作者工作台，不是他人使用的访客账户。

## 发布副本与本地导出（已包含在 alpha.17）

正文工具栏打开“导出与发布”，进入前先保存当前稿。填写公开书名、署名，展开填写简介、版权和 AI 说明；这些字段由作者明确提供，不自动复制私人设定。章节初始不选，可选全部有效章、仅定稿或逐章选择，在已选列表上下调整顺序。Ctrl+S 或“保存表单”仅暂存选择和字段，不创建副本。

“创建发布副本”冻结当时的正文、章节顺序和公开信息，后续改稿不会改旧副本。捕获读取阶段可取消，进入提交后须等待完成。副本保存在作品内，整书备份包含它；本机尚未创建的表单草稿不在整书备份内。损坏/未知版本表单会保留并提示，明确重置才放弃；本机草稿空间不足会阻止关闭，先重试保存或明确放弃。

在已保存副本中预览单章，选择 TXT、Markdown 或 HTML，再“导出此副本”选择目标文件夹。程序创建带独立 ID 的新子目录，写入清单并核对文件哈希，取消选择不创建文件。TXT/Markdown为 UTF-8；HTML包含目录、上下章、主题与字号，可从 index.html 独立阅读。请连同全部 HTML/CSS/JS 文件一起保留。导出完成是本地副本，不表示已上传网站或获得出版许可。

当前快照上限暂定32 MiB，PDF/DOCX单次排版内容上限8 MiB；alpha.25可将选定封面/插图冻结并导出带图HTML；带图副本暂不支持TXT/Markdown/PDF/DOCX。尚未完成地图嵌入、EPUB与远端发布。图像资源和地图在独立创作工具中管理。真实 Windows 原生目录选择已在本机开发环境实测；发布界面、三格式产物及390px独立页面通过alpha.17本机和标签CI的实际安装验证，PDF在alpha.22加入，DOCX在alpha.24完成安装及独立发行。原生对话框交互不作为CI自动点击通过；详见README的对应版本报告。

## 小说图像资源（已包含在公开alpha.18）

写作工具栏打开“图像资源”，进入前先保存当前章。导入PNG/JPEG/WebP静态图像；原图完整复制到作品中，预览按方向生成，替换保留旧版。单张暂限20MiB/2000万像素/单边16384，仅支持可安全创建不可变文件的本地书库。

选择用途、填写来源和权利说明、关联人物或地点资料，再保存说明；Ctrl+S保存当前说明。用途为封面/定妆只是分类，不自动选择出版资源或调用图像服务。未保存输入暂存在本机，临时空标题可恢复，未知草稿保留到明确放弃。配额失败保留窗口；确认已保存但清理失败时先重试清理。

外部说明改变时旧保存被拒绝，点击“读取磁盘版本供对照”核对后可明确保留调整并采用当前基线。查看历史图像不会改变当前版；“采用此历史图像与说明为新版本”会恢复当时图和说明并保留之后版本。回收不删除原图，仍可恢复。预览校验失败不自动修复损坏原图。

若导入结果未确认，先检查这次导入或重启后核对待确认记录，程序按同一身份找回，不能把错误提示当成原图从未保存。取消选择不创建记录。已保存原图/说明/历史进入整书备份，本机草稿与待确认标记不进入备份；生成前会预检与512MiB恢复限制一致的容量。裁切与定妆选定仍未实现；AI生成见末节。导出面板可另选出版封面/章图并冻结为带图HTML，图像资源的用途标签不会自动批准出版。

## 世界地图（已包含在公开alpha.20）

工具栏“世界地图”先保存正文。可新建多张地图，手工添加地点、绘制区域、连接路线，填写年代标签和地点资料关联。坐标表单采用0至100百分比；地点一行，区域每行一个顶点，路线填写中间折点。选中图上地点后方向键移动，Shift精细移动；空白画布方向键平移，缩放不改变正式坐标。窄窗先展开目录查找对象。

从本书图像资源选底图会冻结其当时版本。后来更换资源不会改地图；更换为不同原图会清除比例尺，需重新核对。作者明确填写比例尺两点、距离和单位才换算路线距离，不推断实际行程时间。地图派生预览最长2048px，不替代原图精细制图。

“保存地图”或Ctrl+S提交一个修订。未填完的坐标、区域和比例尺仅存本机草稿，可关闭后继续；未保存输入不进入整书备份，已保存地图/历史/底图进入备份。存储空间不足阻止关闭，可完成输入并保存到作品；未知草稿只读保留，明确放弃后才清理。外部修改拒绝旧保存，可先读取磁盘对照，再明确采用基线保留当前调整。保存清空未保存撤销栈；查看历史只读，采用历史另建版本。回收不删除旧图，可以恢复。图层时态、角色路径推演、AI地图生成与带图出版仍在后续。

## 地图年代与层级（alpha.21已公开）

世界地图面板打开“年代与层级”，把地图加入目录，创建作者年代组并按需要上下调整顺序。为城市图/室内图选择父图和父图的一个地点或区域锚点，明确保存；父图尚未入目录时会同时加入顶层并提示。不同地图坐标与比例尺互不转换。目录中打开地图或回到父图；年代组和层级筛选只切换明确关联的地图，不推断故事先后，也不叠加不同坐标的图形。父子图分属不同年代组会提示核对。

未填完的年代名、锚点和暂时循环选择可保留本机，正式保存会拒绝空名称/循环/缺失关联。Ctrl+S只保存最上层地图册对话框。窄窗通过“展开地图目录/收起地图目录”切换目录与编辑表单，选择目录项会回到该图的表单。删除年代组前先解除地图关联；有子图的目录项不能直接移除。移除目录位置不删除地图原件，回收或损坏地图的旧关系会保留并诊断。

本机草稿空间不足会阻止关闭，完成有效输入后仍可保存正式目录。未知草稿只读保留到明确放弃；已保存但清理失败时先重试清理，不重复保存。另一份本机草稿发生变化时不会覆盖它，当前窗口仍可明确保存到作品；再次打开旧草稿须对照新存档后再处理。外部目录修改也会拒绝旧保存，明确读取磁盘对照与采用基线后再保存。

查看目录历史不改变地图；采用历史另建目录修订，不回退地图图形。历史目录中的地图名称来自当前地图，关系/年代组/说明来自历史记录。已保存目录与历史进入整书备份，未保存本机草稿不进入备份。每书暂限1000个目录节点、128年代组、32层和1MiB目录文件，单次最多更改40个地图引用以保持正文响应。当前没有自动故事时间、空间叠图或AI地图册写入工具，不能当作正文事实推演。

## alpha.27：增量备份与恢复

作者工具栏“增量备份”先保存当前章节，再打开备份面板。选择书库外的位置创建备份；后续“打开已有备份库”并“追加备份”，每代记录完整文件清单，只新增变化内容。不变内容新增0字节仍会增加完整版本。目录需整体保留或搬移，重要稿件另留不同物理磁盘的独立副本；共享对象损坏可能影响多个版本。

选择历史版本后“恢复所选版本”，核对时间并“确认恢复为新作品”。当前书不覆盖，恢复后自动打开新书。列表先校验清单，恢复逐文件完整校验。任务提交前可取消，提交中需等待；取消可能留下可复用对象，但不新增可恢复版本。备份/恢复期间请等待或先取消，再关闭窗口。

包含作品内已保存正文、资料、历史和原图，不含全局AI任务、模型Key和本机未保存草稿。原有整书完整副本方式仍可用。已随公开alpha.27安装版交付，本机和标签CI完整安装/升级通过；没有自动定时和旧版本清理功能。

## 模型服务与Key的范围

alpha.27及沿用旧设置逻辑的版本修改服务地址时会保留原Key。更换地址前请先在旧地址下清除已保存Key，再输入新服务地址与对应Key，不要将旧Key发送给不信任的服务。已在公开Release说明提示；修复已在alpha.29通过完整验收并公开，建议更新。

## AI 图像工作室（alpha.31阶段预览已公开）

alpha.30安装版没有此入口。alpha.31安装版可从写作页的“AI 图像”打开，打开前先保存正文。在模型设置的能力管理中建立独立图像配置/Key，按服务文档明确选择默认返回内联base64或请求response_format=b64_json，再选择该图像服务。未确认的旧配置不会自动启用；模型管理中的保存本身不调用图像服务。

填写图像用途、提示词、数量与尺寸；人物定妆需明确人物，章节插图需明确章节。只有提示词会发给所选服务，目标版本只用于关联核对，不会自动发送整书或人物卡。先“准备图像任务（不发送）”，核对冻结内容、模型和费用估算，再勾选并明确发送。未填单价显示费用未知，不代表免费；手填预算不替代账单。

返回后逐张审阅实际图像，填写采用后的名称和权利说明，明确采用才会新增图像资源。不会自动替换封面、定妆、地图底图、正文或出版物。目标发生变化时拒绝旧采用，保留输入与候选。窄窗可在新图像、任务记录和候选审阅间切换。

取消只停止本地等待，已发送时可能仍计费；未知结果不会自动重试。图片返回但磁盘保存失败时留在当前进程，“重试本地保存”不会再发网络请求。退出前需完成补存或明确放弃；明确放弃不退费，未落盘原图可能无法找回。普通提示词/采用说明草稿仅在本机，未来格式缓存保持只读直至明确放弃。书内正式任务与候选随作品备份，重启不会接续原请求。
