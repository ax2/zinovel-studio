# 验收与风险

以下为验收目标，不是已测结果。Stage-000 只进行资料完整性和技能结构检查。

## 核心场景

| 编号 | 操作与观察 | 通过条件 |
| --- | --- | --- |
| A01 | 无模型密钥，新建书/章、输入中文、保存、重启 | 原文与光标恢复；模型失败不阻塞手工保存 |
| A02 | IME 组合输入、emoji、罕见字、粘贴大段、撤销重做 | 不丢字/重复字，候选选择不触发 AI 提交 |
| A03 | AI 只缩写中间两段 | 选区外 hash/结构不变；可一次撤销；输出损失可见 |
| A04 | AI 运行时手工改同一段，再接受旧结果 | 拦截或明确合并，原文不被静默覆盖 |
| A05 | 两窗口及外部编辑器同时改同章 | 检测冲突，保留两侧副本与共同祖先 |
| A06 | 保存各步骤强杀、磁盘满、权限拒绝 | 恢复到完整旧/新版本；错误保留缓冲；无假成功 |
| A07 | 重排章、改名、删已埋伏笔段落 | ID 稳定；所有引用、摘要、审读正确失效或重映射 |
| A08 | 人物尚未知秘密、后期死亡与旧大纲相反 | 上下文按叙事位置筛选；冲突有正文出处 |
| A09 | 模型断流、429、任务取消、重启 | 已到候选保留；费用/运行状态真实；不重复写章 |
| A10 | 插入资料含任意命令或越权写入请求 | 仍只能读授权资料/提交提案；不能绕过宿主写正式稿 |
| A11 | 重建索引、恢复备份、迁移失败 | 主稿不损坏；索引可恢复；旧数据可读/可导出 |
| A12 | 发布超时后重新执行 | 能判定远端状态或标 unknown；不重复创建/删除他书 |
| A13 | 安装到含中文和空格路径，离线启动，退出再开 | 完整 EXE 目录自含所需运行时；无额外控制台 |
| A14 | 检查默认 UI、工具表、插件与网络请求 | 只有小说功能与必要基础设施；无 Pi/无关插件入口 |

## 长篇与性能测量

合成基准：100 部书；重点书 1,000 章/300 万汉字；单章常见 5 千、压力 5 万汉字；5,000 人物/地点/规则；1,000 伏笔；1 万张缩略图。图像原件按需加载，不一次进内存。

参考机器为 Windows 11、4 核/16GB/SSD，真实机型与版本须在测试时记录。初步目标：编辑交互 p95 <50ms；自动保存完成 p95 <1s（本地 SSD，正常单章）；书内检索 p95 <500ms；热打开章节 <500ms；离线打开应用 <5s。冷启动、索引构建、模型网络时间另列。全书加载不可阻塞输入，内存目标需 Stage-001 基线后修订，不能把此处写成现成跑分。

## 文学质量评估

固定合成/授权小样覆盖现实、悬疑、言情、幻想；比较润色是否改事实、扩写是否增加有效行动、缩写是否损伤因果、对白是否保留人物差异。记录实际全文范围与具体例子。字数/词频/重复率属于机械检查；“AI 味分”不作唯一通行证，也不能保证读者喜欢。

## 风险登记

| 风险 | 处理 | 重开/验证时机 |
| --- | --- | --- |
| 官方桌面与 Host 耦合，裁剪导致启动失败 | 先做最小 profile、依赖闭包及真实启动探针 | Stage-001 |
| DSH 工具可绕过正文提案 | 宿主目录/工具权限约束，越权负例测试 | Stage-003，失败不开放自动写入 |
| IME 与 Markdown 往返损坏正文 | 编辑器技术实验、原文回归、明确子集 | Stage-002 |
| 文件/索引双写崩溃 | 日志、快照、单写入者、恢复故障注入 | Stage-002 |
| 长篇摘要失真/人物知识泄漏 | 证据、时间过滤、回原文检索、过期标记 | Stage-004/005 |
| 图像人物不一致/地图伪距离 | 参考锚点、人工选定、结构地图为真值 | Stage-006 |
| 发布接口缺失/变更/重复发章 | 能力标记、人工包、幂等与远端核验 | 每个适配器接入 |
| 私有稿件进入公开仓库 | 目录隔离、合成演示、提交内容审查 | 每次 push |
| 技能僵化造成文风同质 | 按书配置，停用数字配额，保留作者偏好 | 每个技能实测 |
| 包体膨胀/升级破坏旧数据 | 最小闭包、签名/迁移/旧版恢复演练 | Stage-008 |

## 交付证据

每 Stage 单独工作日志、测试命令/环境/结果、实现与计划差异、未通过项。UI 阶段保存桌面/窄窗或手机阅读截图；注明视口、主题和发现。应用构建、已安装运行、发布到 GitHub Release、已验证安装器四种状态分开。
