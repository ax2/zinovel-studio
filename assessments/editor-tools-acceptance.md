# EDIT-06 / EDIT-07 行为验收

2026-10-22，Windows 本机真实 Electron 44.7.0，浅色，窗口设置 1008×750（DPR 1.25，截图为实际像素）。数据为测试新编合成文字，未调用真实模型。

## EDIT-06：批注、书签与定位

通过 `tests/annotations.test.mjs` 和 `scripts/smoke-editor-tools.mjs`：

- 批注、书签和场景标记单独保存，新增不改变 Markdown 正文；进程关闭再启动保留内容、处理状态和锚点。
- 前文插入后，唯一引文重新定位；真实 UI 跳回准确原文选区。
- 引文删除时明确“原文已改变”，定位按钮禁用；重复引文无法唯一判断时返回 ambiguous，不猜测位置。
- 作者可显式绑定当前选区，标为已处理、回收与恢复；事务保留历史。
- 批注版本、文件 hash 和正文 hash 同时校验；竞争修改或外部正文改变使旧请求失败。
- 整书备份恢复后，标记、状态与定位保留；原书不被覆盖。

当前实现为本章列表和弹窗，不等于全文场景看板/拖拽层级/跨章移动。锚点是引文与邻近上下文的文字对应，不推断故事语义。超过 1000 个重复位置保守标记歧义。无全文的自动语义重绑定。

## EDIT-07：逐项替换预览

通过 `tests/replace.test.mjs` 和真实 UI：120 处字面匹配分页显示，清空默认全选后仅勾选第 1/52 处，切回页面仍保留选择。应用后只有两处改变，其他 118 处逐字不变；一次撤销恢复精确原文。取消选择时应用禁用，查询或替换内容变动时旧预览失效。

支持当前章节的字面匹配，不执行正则；范围上限和结果大小校验明确报错。接受前仍检查作品 ID、章节 ID 和全文基线，防止覆盖期间的编辑。
