# 试写实验室：手工工作流验收（2026-10-23）

范围：alpha.9 主分支源码开发版本；公开 alpha.8 不包含本增量。IDEA-02/03/04/05/08 手工部分有实际证据，完整 AI 试写任务与新版本安装尚未验收，条目保持 in-progress。

## 实际行为

- 建立固定场景实验，明确关联资料并冻结版本；资料后来变化时显示待核对，原始场景及资料快照保持。
- 同场景复制独立样稿，编辑视角、声音、人物行动、阻碍、读者承诺及正文。并排查看真实文本，窄窗纵向比较。
- 明确选择保存完整版本和作者理由；后续改稿提示选择已过时。试读来源/反馈与原稿快照一起归档，不随新稿变化。
- 手工中文插入、键盘撤销/重做、暂时空标题与未保存正文均通过真实关闭/重新启动恢复。此证据不等于真实 Windows IME 候选确认验收。
- 同版本外部正文和元数据改写均触发 CAS 冲突；先对照磁盘，再明确保留本地调整并重定基线。被替换的磁盘稿进入历史，未自动覆盖。
- 注入 localStorage 配额错误，界面禁止切换样稿和关闭；真实 BrowserWindow.close() 被主进程关闭协议取消，明确 Ctrl+S 保存后解除保护。
- 回收站恢复身份与正文；明确建立新章节，原首章 CRLF/Unicode 完整字节不变。同一版本重复转章返回同章，备份恢复后的新作品保留分支、选择、反馈及转章回执。

## 验证与修正

`tests/pilots.test.mjs` 五项存储测试覆盖上述版本/隔离/回执/备份边界，并验证共享日志在试写元数据先写入、正文未写入时能够重启恢复。无效 UTF-8、未来 schema、目录 junction、跨书引用均拒绝且不改原文件。

`pnpm test:pilots` 运行真实 Electron。Browser plugin not available，使用项目 Playwright Electron 流程，独立临时数据及合成作品，无真实模型费用。报告 screenshots/stage-004/pilots/pilots-smoke.json passed，pageerror 为空。

首次完整运行发现共享编辑器把 CRLF 初始化为规范化文本，再由属性同步产生双换行，最终自动保存改变首章。保留失败证据至本机 .cache，修正 CodeMirror 显式 LF 分隔并保留原始 CR 字节；相同真实脚本重新通过原始文件 Buffer 比较。不是将测试输入改成 LF 回避问题。

75 项单元、类型、规划与构建通过；受影响的正文编辑工具、正文证据、渲染崩溃/关闭恢复及三方冲突合并桌面套件全部重跑通过。既有对话框 Ctrl+S 不会误存背景正文，新试写保存按钮显式声明快捷键入口。

查看 1426×923 浅色和 806×803 深色截图，比较字段和正文可读，固定标题栏关闭按钮可达，页面/对话框无水平溢出。初版左侧编辑表单与右侧只读文字不对齐，改为比较时两份只读样稿并排，退出比较继续编辑；原编辑器保留挂载，不因查看对照丢失撤销栈。
