# 独立试写 AI 与实验闭环验收（2026-10-23）

范围：alpha.9 开发源码；安装包和公开发行证据另记。上一手工提交 f252cef 的 CI 39961429122 completed/success。本报告补充手工验收，不改写此前尚未实现的历史记录。

## 已验证行为

- 官方 Harness SDK 使用独立 pilot 任务，只暴露冻结读取和候选提案两个工具。真实本机 SSE 服务完成三轮工具请求；预览、预算预估和过期快照拦截都不发模型请求。其他试写、未选资料、正式章哨兵均未进入请求。
- 候选出现后磁盘样稿仍不变。逐块审阅/手改、显式保存审阅草稿、同会话再开及真实关闭/重启均保留。明确接受仅修改试写正文，保留标题、声音等作者字段，正式章 CRLF/Unicode 原始字节与其他样稿不变。
- 外部修改正文或固定场景会拒绝旧候选。作者选定版本的更新不影响冻结场景身份。实际取消停止在途任务，旧候选保留为待审阅，重启不重放请求和候选。
- 独立子进程在接受意图落盘后、样稿事务完成后分别 exit(91)。新宿主恢复前者至待审阅，后者凭事务回执确认已接受；后来作者的修改保留。部分书内事务恢复后回执有效，不会二次覆盖。
- 全局任务详情识别独立试写身份，不显示旧版无章节警告或正文选区重试。任务列表、审阅草稿都按书和试写身份绑定。
