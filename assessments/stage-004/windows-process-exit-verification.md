# Windows 故障探针进程退出核对（2026-10-23）

alpha.11 测试设施改进，应用产品功能与公开 alpha.10 字节未变。归档提交 f7cb189 的 Development checks 39975552846 在任务恢复探针中 process.kill(pid,0) 报 EPERM；标签发行 CI 39975497797 和标签源码开发检查 39975497738 均成功。未把单个归档工作流失败描述为发行成功，也未重跑旧提交来隐藏问题。

退出验证现使用 Win32_Process 的 ProcessId + CreationDate。先捕获 Playwright 自己启动的桌面根 PID 及后代身份，强制终止仍只针对该根 PID；之后枚举确认原身份均已消失。相同 PID 被另一个创建时间的新进程使用，表示原进程已退出，不会继续终止新进程。无法读取创建时间、CIM 查询错误或超时均使检查失败，不能当成退出证据。

一项身份测试覆盖原进程存活、真实消失、PID 复用、目标身份不可读和无关进程不可读。当前完整 90 项单元、类型和规划通过。真实任务/流式故障探针使用同一辅助模块，验证强制退出、已持久化候选/可见片段、真实重启及正文不自动改写；报告标记核对方法，保留实际退出计数。

旧流式探针捕获所有 kill(pid,0) 错误并当成退出，单凭这一部分不能证明全部子进程已退出；原始报告保留，不回写伪造更强证据。新的两个探针均明确核对进程身份，并继续保留原有稿件恢复和无自动重放检查。该改进不替代完整启动稳定性、低端设备或商店验收。
