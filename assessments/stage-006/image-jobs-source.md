# alpha.31 图像协调服务源码切片

ImageJobService为宿主专用模块，尚未注册到renderer IPC、ModelSettings图像入口或作者界面。现有profile仍runnable=false，不能称实际桌面已可生成。测试使用合成宿主解析器的明确适配选项，不等于实际系统加密配置接通。

prepare只接受任务ID、request、target和作者看到的model choice；预算/模型身份由宿主解析，renderer不能提供Key/服务地址/模型profile。start重新核对原任务与所选profile修订，网络前再次解析确认并保存发送意图。没有回退供应商或自动网络重试。全局只允许一项运行或待补存结果，避免并发付费响应无限累积；不是RSS峰值或大图性能认证。

已返回图片本地保存失败时保留当前进程中的一份有界response，status只公开身份/阶段/保留事实。retryLocalSave只读当前回执并补存，已提交但丢确认则核对原返回hash/说明/用量/取消标志后本地完成；拒绝换接收结果。HTTP/取消/未知结果保存失败也保留固定outcome供本地补存。whenIdle返回false提示仍有待处理结果；主窗口关闭拦截尚未接入，不能称已经阻止真实窗口退出。明确、CAS核对且持久化的放弃回执成功之后才释放未保存原图；进行中不能放弃缓冲。

同进程发送意图所有权提前到commit前登记：durable commit已成功但返回失败时，协调器仍可保存传输层确定的未发送事实。新进程不拥有该身份，仍按既有远端未知规则，不把意图等同已发网络。

10项服务专项、完整311项/类型/规划与构建通过。真实本机HTTP合成Key/图片：成功一次请求、禁用适配/模式/凭据字段拒绝、模型过期及私有codec错误不外泄、解析等待时取消零请求、实际收请求后取消unknown与全局互斥、返回图片落盘失败后仅本地补存、明确放弃、已提交无回执本地核对、429结果写失败本地补记、发送意图commit成功无确认但HTTP零请求仍正确not-sent。均不访问真实供应商，不把单测当文学/视觉质量、原生DPAPI、桌面关闭或安装验证。
