当前是alpha.41源码，无安装与公开包资格。8项有实际文件操作的单元测试通过：创作资产UTF-8/BOM/CRLF、并发编辑冲突及外部前像、版本历史、备份恢复新身份后续写、占用路径和未知清单保留、队列输入捕获、受控路径、写作工程与Astro导入、旁车错误、确认时源变更、计划-only与链接拒绝。

实际Electron三组作者操作见[桌面报告](../../../screenshots/stage-002/book-project/book-project-smoke.json)：书架导入 → 合成工程只读预览（1章/6文档） → 总纲Unicode输入与保存 → 外部改稿后保存冲突，缓冲和磁盘均保留 → 未存关闭阻止 → 整个应用退出/重启 → 外部版本明确复核保存并留历史 → 旧历史仅载入缓冲 → 新建第二卷细纲。原始源工程与导入正文逐字节保持，控制台pageerror为空。原生文件选择器返回合成路径；未验证系统原生IME或真实模型。

查看1186×863浅色、792×766深色截图后，修正深色编辑框白底与正文区域过高；最终重跑保持同一交互链和冲突断言。新建作品宿主默认创建13份标scaffold的待填写模板，旧书显式初始化时任何已有未登记资产阻止覆盖。源码API保留无工程的旧书兼容路径。

首轮真实失败见first-failure：祖先目录junction被过严拒绝，影响正常选择workspace junction下的普通工程目录。现在拒绝选择本身的链接，将普通选择绑定到canonical root后再拒绝其内部链接；不跟随源工程内部链接。第二轮QA未等历史异步响应即断言，third-qa-locator使用不存在的深色按钮名，两者为测试错误，产品语义未放宽。全部原报告保留，不称首次即通过。
