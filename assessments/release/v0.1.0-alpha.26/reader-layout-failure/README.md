# 阅读布局缺陷与资格撤销

源码5870883候选的第三轮机器检查151项passed，安装10717ms、重装17894ms、卸载5138ms；完整原稿精确保留、EXE/注册项移除。但查看安装截图发现：986×863内容视口、参考面板展开后进入独立阅读，头部/控制栏/目录变成多个隐式列，正文被挤到屏外。故撤销本机候选安装资格，未据机器passed创建发行标签或升级资格。

原因：工作台窄屏选择器.show-inspector footer匹配了阅读弹层内的footer，将grid-column:2/5施加给阅读网格，创建隐式列。阅读页自己的类选择器不能覆盖更高特异度。修正为只作用工作台直接子footer，并同步限制基础和普通窄屏footer规则，避免其他模态页继承布局。

新探针先检查DOM文本、边界与dialog.scrollWidth，仍曾错误放过宽度为0的正文段落；这些条件不能证明可读。补正文最小可用行宽检查后，未修正样式的实际源码重现失败（段落宽0、竖排324高、右侧屏边），回执reproduced-zero-width.json保留。修复后实际同视口段落宽661.4、高36，阅读主体657.2高，四段可见且无横向溢出，已查看更新截图。该断言进入离线源码与安装门禁，不通过更改阈值掩盖布局问题。

所有旧机器passed回执和坏图保留；修复候选必须重新构建、独立阅读回归、完整安装/重装/卸载及旧版升级，不能继承被撤销资格。alpha.25已公开版本不在此文档中冒称同场景修复完成。
