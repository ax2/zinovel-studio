# 持久出版快照存储层（alpha.17）

已实现存储接入，尚无出版菜单、作者范围选择或保存对话框，不提升任何 PUB 功能为 verified；alpha.17 门禁保持 false，alpha.16 冻结标签/流水线不受开发改动影响。

PublicationStore 与其他作品服务共用 BookStorageKernel。目录投影只取有效卷章/保存版本，基线 hash 绑定目录；捕获校验重复/跨书/删除章节，按作者给定顺序逐批严格读取与重验正文，批间释放队列。容量暂设32MiB，未取得千章性能资格。公开书目使用现有白名单，正文和公开元数据独立复制并持久保存，读取时重建严格 schema/hash。作者资料、任务、未选章节不纳入快照。

取消发生于捕获/重验时不创建快照或新恢复日志；提交前关闭取消后返回实际已提交的快照，不能把已保存结果标为取消。进度回调在队列外，可再次访问同一目录而不死锁；提交状态回调必须同步。输入在第一次 await 前复制，调用者后改选择或书目不会偷换捕获请求。正文外部改变会在重验拒绝；再次明确捕获会保留实际字节和保存/实际双 hash，供后续预览显著提示，不自动改写原稿。两遍读取仍不声称跨进程全局冻结。

新快照通过事务 create-only 前像条件写入，已有路径拒绝覆盖；未知前像条件或 Windows 大小写重复路径在创建新日志前拒绝。损坏/未知版本快照逐项报告并原样保留，其他有效快照仍可列出。重启后只读取已持久记录，不重放捕获或导出。

备份保持快照原始字节；恢复新书在非冻结书目中记录原书来源链，快照内部原书 ID 与内容 hash 不变。连续两次备份恢复仍可读取原快照；无来源关系的跨书复制被拒绝且保留文件。来源链上限128，损坏或越界在创建恢复目录前拒绝。未承诺旧版降级软件理解新增出版记录。

新增9项存储回归全部通过，涵盖选择/排序与秘密排除、改稿后冻结不变、重启、范围/目录基线、同队列取消、外部字节变化、坏UTF-8/容量、损坏快照、两次恢复及跨书拒绝、前像防覆盖和提交取消边界。完整 pnpm check **146项通过**。同9项测试在实际 Electron44.7 的 **Node24.21** 下通过，属于源模块兼容性检查，不是假称已安装出版界面。
