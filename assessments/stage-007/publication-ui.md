# 发布副本界面与本地导出（alpha.17）

当前源码已接入作者界面与真实宿主：写作工具栏→导出与发布→显式选择与排序章节→公开信息→创建发布副本→逐章预览→本地TXT/MD/HTML新目录。进入前保存当前编辑，表单保存与Ctrl+S不创建副本。已保存副本独立于后来表单/原稿更改，重启后可读取；未知/损坏副本保留诊断。

Browser plugin未列出，采用仓库Playwright/Electron，未安装新浏览器依赖。真实窗口页面身份、非空工作台、实际操作与截图通过，无框架覆盖层、页面/控制台错误或页面外部HTTP请求。桌面1426×923、窄窗806×803、深色窄窗已实测并查看；390px独立HTML与真实Windows目录选择已另行补验，见publication-native-html.md。首次长表单曾把标题/关闭入口滚出视口，现改固定头部、分栏滚动和可选信息折叠；窄窗为单栏，正文可独立滚动。未将窄窗当作真实手机。

PublicationCaptures按窗口/作品隔离，最多2个活动任务，状态仅返回进度与副本身份，不返回正文。捕获可取消，提交关闭取消；关闭应用会取消读取或等待提交。导出在原生目录选择前校验副本，选择返回后再次按同一ID/hash重读；未提供有效hash不打开选择器。应用关闭等待已启动导出，避免窗口销毁截断自己的写入。

真实界面已验证：未保存正文先落盘；公开信息与反转选章顺序保留；Ctrl+S仅保存表单；捕获后的正文脚本按文字显示、不执行；未选章节和作者资料不进入预览/文件；缓存配额失败阻止关闭并保留输入，恢复后可重试；未知版本表单跨窗口关闭/真实重启原样保留，明确重置才替换；之后修改表单和原稿不能改变选中的旧副本导出。

三格式真实宿主文件写入已在中文空格目录逐项核对字节/hash；目录取消不创建文件，重复导出身份/无效内容不覆盖既有目标。输出清单仅标exported，不是远端公开。无分卷正文不会把内部“未分卷”标签写入书中，失联分卷阻止新捕获。测试目录选择结果被替换，**不冒称原生对话框操作验收**；原生交互与实际独立打开产物由独立探针另行通过，见publication-native-html.md。导出过程自己的暂存目录失败时保留，不递归清理他人目录。
