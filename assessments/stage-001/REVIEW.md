## 已验证

- Windows、Node 26.10.0、Electron 44.7.0、pnpm 10.3.0。官方运行库 SHA-256 `eee30dc8fa1f5ea95490e59f44e46ea68dd24c6e93d22facf70fe5c2d4c2665c` 校验通过。
- `pnpm check`：TypeScript、7 项存储/权限测试、104 功能/21 技能/20 合约的结构检查通过。
- `node scripts/check-upstream.mjs`：官方固定 Git blob 的 3 个源码/许可文件哈希一致。
- `node scripts/smoke-harness.mjs`：官方 SDK 与真实 Agent 进程完成文本回合，关闭后的通用工具列表为空。
- `node scripts/smoke-novel-agent.mjs`：官方进程真实调用 2 个小说工具、返回候选、取消运行中的任务；只有两个小说工具暴露。
- `pnpm test:desktop`：真实 Electron 窗口完成作品/章节创建，中文、𠮷、emoji 写入，保存后磁盘核验，立即关闭与重开，外部冲突拒绝覆盖及历史恢复。
- 同一桌面测试完成系统凭据加密存储、选区候选生成/对照/接受、生成期间手工修改后的过期候选拦截、隔离 renderer 与 IPC 非法操作拒绝、窄窗参考抽屉。

模型端全部为本机确定性 SSE fixture。它验证官方协议和 Agent/tool/UI 链路；不证明真实 DeepSeek 账户、网络服务、计费或文学质量。

## 尚未覆盖及调整

- 当前为源码开发启动，未产出正式安装器、签名、自动升级或商店提交。没有把一次 build 称为可发行版本。
- 中文内容真实写入/重开通过，但尚未做 Windows 系统 IME 候选窗的人工输入验收；组合事件测试和系统 IME 要分开记录。
- 编辑器是用于可靠性实验的原生 textarea；卷/场景、富编辑、完整撤销语义、批注、长篇性能和可访问性仍待完成。
- 21 技能能被读取选择，但只有通用候选通路经过 fixture；每个技能的具体工具、结果结构和文学效果仍不能标 verified。
- 两个当前工具只覆盖冻结选区/文本候选子集；20 项领域工具完整合约继续保持未完成。上游完整 Office Desktop Host 未构建，采用文档化的官方生命周期派生 + 公开 SDK profile。
- 依赖包包含上游传递依赖，不表示它们已激活。需要继续输出完整活动插件清单/网络清单、裁剪包体、原生模块与许可证审计。
- Electron 测试依赖的 Windows launcher 出现 DEP0190 弃用提示；应用自身未调用 shell 命令。发行测试需更换/校准测试运行器并复测。
