# ZiNovel Studio 0.1.0-alpha.28

本阶段新增当前会话故障诊断，便于排查写作、备份和AI调用问题。Windows x64预览安装程序随通过发行门禁的Release提供；安装不需要Node、pnpm或Python，当前未代码签名。

- 侧栏“故障诊断”查看最多200条固定操作元数据；不收集正文、提示词、候选、书名/ID、路径、模型地址、Key或原始异常/堆栈。未知失败归为固定类别，不靠替换敏感字串来脱敏。
- 分钟时间、操作类型和耗时档仍反映使用活动，分享前可预览；没有自动上传或默认诊断磁盘存档，退出即清空。可明确清空当前会话，不删除原稿或AI任务。
- 手工导出需原生文件选择，只创建新JSON，拒绝覆盖已有文件以及应用数据目录/别名。导出期间保留关闭保护，取消不写入文件。
- 诊断表示宿主调用返回结果；后台备份的最终状态仍在对应窗口查看。AI私有任务和官方SDK会话存档不进入此包，完整上游日志审计继续。
- 源码与安装EXE分别验证隐私、目录边界、退出重启和原稿保留；标签流水线必须独立完成全部安装、重装、卸载及早期版本升级后才公开附件。

继承alpha.27已交付的增量备份与选版恢复。完整106项仍继续推进：当前会话诊断不等于全日志审计，真实模型文学质量、原生IME/辅助技术、大书性能、自动备份策略、EPUB和带图DOCX/PDF、远端发布及商店资格尚未完成。
