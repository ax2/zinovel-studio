# ZiNovel Studio 0.1.0-alpha.12 — 作者认知选择与旧记录整理

作者可以明确采用某一条有效认知事件作为当前选择，矩阵单独显示选择与所有相反记录。选择冻结事件、正文和定义所对应的版本；事件、正文或设定改变后显示待复核，保留当时的状态与引文，不按最后编辑时间自动改选。可以清除选择、查看历史，重新绑定事件后仍须明确重新选择。

旧认知可在矩阵中搜索、分页查看并带入新命题记录。作者核对范围、人物与状态，再绑定当前已保存正文的选区；旧资料和旧事件保持原样，新事件与冻结来源同一恢复事务写入。来源会区分原事件未变、改变/停用、失联、旧资料其他改动以及新记录修订；来源无法读取也会保留文件并提示，不隐藏仍可读取的新认知。

认知及来源草稿支持真实退出后恢复；过期旧资料基线拒绝创建。保存后折叠空编辑区，减少查看记录时的滚动。认知事件严格解码UTF-8，坏字节在写入前拒绝，防止替换字符覆盖原数据。旧alpha.11真实打包EXE的合成认知回退测试通过，不代表NSIS安装器降级或全部应用数据迁移。

Windows x64未签名预览。附件为安装EXE、SHA256SUMS.txt、release-manifest.json、runtime-inventory.json，无ZIP。本标签流水线完成全套检查、实际安装运行、重装/卸载保稿和公开alpha.3覆盖升级后才公开附件。安装前关闭旧应用并备份作品，具体提交和哈希见清单。

完整上架资格仍未完成。独立认知和作者选择尚未接入写作Agent冻结上下文，不能声称AI已自动遵守人物知情范围；自动故事时间推演、大书性能、完整迁移、多格式出版、图像地图、签名/自动更新及真实云模型文学质量仍待完成。整书备份包含认知、选择及来源，不包含应用级任务和本机未保存草稿；正文导出不包含这些独立记录。

发行前故障复评另修复本机草稿清理失败导致新认知重复创建：界面区分已保存与仅草稿清理失败，可检查/找回已有存档并保留当前调整。同一新建草稿的重试不会再次创建，后来作者版本仍须明确核对后修订。早期未发行候选已单独保留，最终附件须来自修复后的重新构建与安装验收。
