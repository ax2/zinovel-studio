# ZiNovel Studio 0.1.0-alpha.15 — 独立阅读预览

从写作工具栏打开“阅读预览”，先保存当前稿，再按分卷目录连续阅读。可筛选定稿、调整字体行距与三种主题，使用 390px 手机宽度模拟。正文按纯文字展示，阅读窗口隐藏作者设定和编辑工具。

按作品在本机记录阅读段落与偏好，真实重启后恢复。正文改版或目录删章会提示，不猜测旧位置；损坏或未知版本进度保留，明确重置才替换。进度不包含在作品备份中，手机宽度模拟不等于真实手机支持，阅读预览也不是安全访客账户。

Windows x64 未签名阶段预览。附件提供安装 EXE、SHA256SUMS、release-manifest 和 runtime-inventory，无 ZIP。仅同标签完整 CI、实际安装后全套、重装/卸载保稿及公开 alpha.3 升级通过才发布。安装前备份作品并关闭旧版。

完整上架资格未完成。插图地图、阅读大书性能、辅助技术、真实模型文学质量、多格式出版、代码签名和自动更新继续开发。106 项完整需求持续跟踪。

发行验证按程序原有任务预算观察候选，失败报告仅保留任务元数据；强退恢复须核对原属进程身份全部退出，卸载须确认程序和注册项都已移除并保留稿件。安装全套与升级未通过时不发布附件。
