# ZiNovel Studio 0.1.0-alpha.36

Windows x64阶段预览，包含可执行安装程序，继续使用官方DeepSeek Harness。

- 卷章树加入有序计划场景、搜索、20项分页、未安排/失联/回收状态。右侧位置菜单支持键盘上下移动和跨卷选章，也可拖到场景之前或章节末尾。筛选不丢隐藏项；只安排计划，不重排正文。

- 缓存失败时阻止切换/移动/关闭并显示未存表单。移动检查原规划版本和字节，外部更改拒绝，明确刷新后才可重新操作；错误在固定工具区可见。
- 新增真实公开alpha.35升级：保留定妆历史、形象草稿、v2图像回执和原图，旧场景草稿不自动正式化；作者明确编辑保存后写新缓存格式。卸载后完整运行目录实际读回已测数据，旧模型Key只用于另外确认的新请求。
