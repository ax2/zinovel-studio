# ZiNovel Studio 0.1.0-alpha.8 — Windows 阶段预览

增加共享场景位置数据、看板和章纲视图，支持拖放、键盘重排、跨章移动、失联引用显示、原场景完整资料编辑和准确章节入口。位置修改不重排或拼接正文。

新增组织、物品、能力和现实资料，现有十二种语义资料类型均支持编辑、检索、版本、历史、章节引用、证据与 AI 提案。现实来源的作者性质标记及核对记录不可被 AI 改写；当前没有自动联网查证。

同时包含公开 alpha.3 之后的候选逐块审阅与草稿恢复、资料证据、关联设定失效提示、正文精确定位、显式资料上下文及结构化 AI 资料审阅。alpha.4 已撤回的问题修复包含在内。

附件提供 Windows x64 NSIS 安装 EXE、SHA256SUMS.txt、release-manifest.json 和 runtime-inventory.json，不提供 ZIP。发行流水线在本标签完成全套检查、实际安装运行/重装/卸载及从公开 alpha.3 升级后才上传附件；准确安装哈希、源代码提交和验证清单以附件为准。关闭正在运行的旧应用后安装，建议先备份作品。

这是未签名技术预览，Windows 可能提示未知发布者，不代表稳定版或商店验收。AI 工具回合使用官方 Harness 和合成模型 fixture 验证；真实模型文学质量、试写分支、关系/认知矩阵、图像地图、多格式出版及完整迁移仍在开发。未保存的本机草稿和应用级任务尚未纳入整书备份，不能把备份作品等同完整工作区迁移。
