# ZiNovel Studio 0.1.0-alpha.5

修复 alpha.4 恢复接受事务后，新保存的审阅草稿可能被旧确认文本遮住的问题。草稿记录其所接续的接受意图 ID，重启后优先展示正确的新稿；旧草稿仍不能覆盖中断接受时已确认的调整。

继承逐块接受、独立审阅草稿、流式恢复和任务费用预算，增加同页同章已有候选比较。不同原稿/选区的版本只读对照，选择兼容版本仍通过正式审阅与宿主接受事务。比较不调用模型，不自动改稿。

Windows x64 技术预览，未代码签名、无应用自动更新，不是完整平台或上架版本。提供安装 EXE 和校验/运行时清单，不提供 ZIP。发布必须完成本版安装、重装/卸载及指定 alpha.3 覆盖升级检查；在标签工作流实际完成前，本文件仅是待发行说明。

当前整书备份不含应用级任务和审阅草稿；跨设备任务迁移、结构化创意/人物/世界/纲要/伏笔、地图/定妆图、出版格式和站点发布等仍在开发。模型验证使用本机 fixture，不代替真实云模型文学质量和账单核验。
