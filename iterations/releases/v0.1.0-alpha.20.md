# ZiNovel Studio 0.1.0-alpha.20

本阶段增加可手工编辑的小说世界地图。正文工具栏打开“世界地图”，进入前先保存当前章；可创建多张地图，添加地点、区域与路线，关联本书地点资料。坐标表单、拖动区域顶点、地点键盘移动和未保存调整的撤销/重做均可使用，窄窗可收起目录。

底图明确选择本书图像资源的一个版本并冻结，后续替换或回收资源不会改变旧地图。更换原图会清除旧比例尺，保留坐标供作者重新核对；最长2048px的方向校正预览不会改动原图。明确填写两点、距离和单位才换算路线长度，不推断正文事实或行程耗时。

保存使用修订和原始hash检查，外部修改先拒绝，再由作者对照并明确处理。历史只读查看，采用历史创建新修订；地图与对象回收保留身份。未完成坐标、区域和比例尺存本机草稿，可关闭/重启继续；配额失败阻止关闭，未知草稿只读保留到明确放弃。结果未确认时检查同一创建身份，不重复创建或回退当前图。

已保存地图、历史及冻结原图进入整书备份，恢复到新书保留来源；未保存本机草稿不在备份内。正式保存清空本次未保存撤销栈，之后使用历史恢复。地图暂限1000个对象、单个区域128顶点和1MiB记录；这些是运行保护，不是小说结构要求。底图沿用静态PNG/JPEG/WebP与20MiB/2000万像素的原图限制。

附件为未代码签名的Windows x64安装EXE。标签工作流需独立完成源码和作者界面、安装后地图与官方Harness回归、重装/卸载保稿、公开alpha.3升级，以及原生图像模块/许可证检查，才发布该标签的精确字节清单。实际结果以成功CI和release-manifest.json为准，本机候选不能代替CI附件资格。

仍为阶段预览。地图图层与故事时态、角色路径推演、AI图像生成、定妆选定、裁切、带图出版及更多出版格式继续开发。自动化目录选择替换结果，不宣称原生对话框点击、原生IME、真实手机、完整辅助技术或真实模型文学质量已验收；全部需求和稳定上架资格仍未完成。

下载ZiNovel-Studio-0.1.0-alpha.20-windows-x64-setup.exe并核对SHA256SUMS.txt；release-manifest.json记录安装、升级与图像运行时证据，runtime-inventory.json记录依赖。升级前保留作品备份。
