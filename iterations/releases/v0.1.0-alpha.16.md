# ZiNovel Studio 0.1.0-alpha.16 — 原文编码保护与独立阅读

修复旧版读取含非法 UTF-8 字节的正文后直接保存可能改写原始字节的问题。正文、作品元数据、搜索、导出与恢复前像遇到损坏编码会明确报错并保留原件；拒绝不完整 Unicode 写入。合法 BOM、CRLF、实际 U+FFFD 和生僻字继续按字节保留。其他编码请使用导入预览，修复不会自动转换损坏文件。建议安装前保留作品副本。

包含独立阅读预览：从工具栏进入前先保存，逐章/分卷/定稿导航，字体、行距、主题及 390px 窄屏模拟；按作品记住段落与偏好，真实重启后恢复。正文改版或删章会提示，损坏或未知版本进度须明确重置；阅读进度不包含在作品备份中。手机宽度模拟不等于真实手机支持，阅读窗口不是安全访客账户。

alpha.15 已撤回为草稿：取消流水线前其上传步骤已经完成，重新核对公开状态后撤回，标签与历史报告保留。alpha.16 必须重新完成源码检查、实际安装后全套（含编码负向回归）、重装/卸载保稿、公开 alpha.3 跨版本升级和标签流水线，才发布附件。

Windows x64 未签名阶段预览，提供安装 EXE、SHA256SUMS、release-manifest 和 runtime-inventory，无 ZIP。源码包含出版快照与 TXT/Markdown/独立 HTML 生成层及独立页面测试，尚未接入桌面出版保存入口，不作为已交付出版功能。完整 106 项需求与上架资格未完成；插图地图、多格式出版、阅读大书性能、辅助技术、真实模型文学质量、代码签名和自动更新继续开发。
