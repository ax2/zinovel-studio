# ZiNovel Studio 0.1.0-alpha.1

首个 Windows x64 技术预览版，面向愿意验证本地写作流程的作者。完整小说创作规划仍在开发，当前不是稳定版或已通过商店审核的版本。

## 可使用的能力

- 多作品书架、卷章组织、归档、导入、全文检索、Markdown 导出与独立目录备份恢复。
- 中文正文编辑、自动保存、历史、冲突三方合并、批注书签、逐项替换、阅读/专注/打字机视图与旧稿参考。
- 官方 DeepSeek Harness 0.2.1-rc.2，通过受约束的选区读取/候选工具进行局部改稿，审阅后接受，可一次撤销。附带 21 项小说方法说明；各项文学质量尚未逐一验收。

## 安装

下载 `ZiNovel-Studio-0.1.0-alpha.1-windows-x64-setup.exe`，按向导选择当前用户的安装位置。无需预装 Node 或其他 AI 桌面程序。普通稿件保存于 `%APPDATA%/ZiNovel Studio/library`；卸载保留用户数据，迁移前建议使用整书备份。

此预览包尚未代码签名，Windows 可能显示未识别发布者。`SHA256SUMS.txt` 用于核对下载完整性，并不替代代码签名。

## 验证与限制

发行工作流只有在基础检查、桌面回归及实际安装后的 EXE 验证成功后才发布附件，详细构建提交、文件哈希和安装检查见 `release-manifest.json`。Agent 验证使用本机模型 fixture 和真实官方 SDK/CLI，不消耗真实账户额度，也不代表云供应商或文学输出质量已验收。

尚未完成：结构化创意/设定/主支线/伏笔、地图与定妆图、长篇记忆及任务恢复、EPUB/DOCX/PDF、网站与投稿发布、应用自动升级、代码签名、真实 Windows IME/读屏器/低配置专项。当前提供 Markdown 输出，不具备全部目标发布能力。
