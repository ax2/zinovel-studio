# ZiNovel Studio 0.1.0-alpha.10 — 全书证据与人物关系图

新增全书证据入口，可集中查找事实、关系、认知和伏笔记录，按章节、事件、知情范围与有效状态筛选。世界记录、读者已知和所属人物已知分别显示，保留停用、删除、失联和待复核记录。每条记录可回到原资料或定位正文引文。

人物与设定关系图保留每次关系变化及其独立依据；选择事件高亮连接，聚焦人物可查看与它关联的记录。图、单事件表格、原资料和正文可以相互核对。当前图最多展示 24 个对象/60 条完整事件，超出会明确说明；表格分页仍可查看全部结果。

修复窄窗创作参考栏遮住工具栏的问题。参考栏打开时暂时收起章节目录，为正文与参考分别留出空间；关闭参考即可恢复目录。修复证据页码在新数据返回前提前更新的问题，损坏资料提示回归正常布局。减少单张资料内的重复关联读取。

附件为 Windows x64 NSIS 安装 EXE、SHA256SUMS.txt、release-manifest.json 与 runtime-inventory.json，无 ZIP。标签流水线完成全套检查、安装后实际运行、重装/卸载保稿及公开 alpha.3 升级后才发布附件。安装前关闭旧程序并备份作品，具体构建提交与文件哈希见附件。

未签名技术预览，完整上架资格尚未完成。5,000 条关系的全量核对在开发机仍需约 3.3–4.7 秒，性能优化继续进行；扫描期间可继续保存正文，结果可刷新核对。秘密矩阵、故事时间切片、图像地图、多格式出版、完整迁移与自动更新仍待完成；真实云模型文学质量未验收，应用级任务和未保存本机输入仍不属于整书备份。
