# ZiNovel Studio 0.1.0-alpha.2

Windows x64 预览更新，重点是 AI 候选和任务恢复。完整小说创作平台仍在开发，本版不代表稳定版或商店验收完成。

## 本次改进

- 写作任务绑定准确书章、正文基线和选区。关闭候选窗口或重启后，可从任务记录继续审阅；旧候选不能覆盖后来编辑的正文。
- 增加全局任务入口、按作品/全部作品/旧版未绑定任务筛选和分页。alpha.1 旧记录可查看、复制，原文件保留，不猜测原章节。
- 中断或取消后保留已落盘提案，部分结果只读。作者可在对应章节用当前选区明确重试，新旧任务分开记录，不自动重发或改稿。
- 作者接受候选时，正文、章节信息与接受回执进入同一存储事务。异常退出后自动核对接受状态，保留作者后续修改；无法确认时提示人工核对。
- 修复准备阶段的并发和取消时序；第二次启动不会误改第一实例的任务状态。

## 安装与数据

下载 `ZiNovel-Studio-0.1.0-alpha.2-windows-x64-setup.exe`。无需预装 Node、pnpm 或其他 AI 桌面程序。普通数据目录仍是 `%APPDATA%/ZiNovel Studio`；手动升级前建议使用整书备份。暂无应用内自动更新。

本预览包未代码签名，Windows 可能显示未识别发布者。核对 `SHA256SUMS.txt` 可验证下载完整性，不能替代签名。

## 验证范围

发行工作流必须通过单元测试、真实桌面回归、打包校验及安装后运行。安装验收除写作、官方 Harness 工具调用、重装/卸载保稿外，还执行任务中断恢复、接受回执故障恢复、旧版分页与显式重试。具体提交、安装字节哈希与检查回执见附件 `release-manifest.json`。

Agent 仍使用官方 DeepSeek Harness 0.2.1-rc.2，集成验证使用本机模型 fixture；不代表真实云模型文学质量已验收。进程退出/强杀测试也不等于物理断电或所有磁盘故障测试。

尚未完成：纯流式片段保留、用量与费用预算、多候选逐块差异、结构化创意/设定/大纲/主支线/伏笔、长篇记忆、地图与定妆图、EPUB/DOCX/PDF/小说站发布、自动升级、签名、真实系统 IME/读屏器/低配置专项等。现有 Markdown 导出和本地写作可继续使用。
