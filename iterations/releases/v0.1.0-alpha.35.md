# ZiNovel Studio 0.1.0-alpha.35

Windows x64 阶段预览，包含可执行安装程序，继续使用官方 DeepSeek Harness。本版优先交付正文与规划数据保护修正，并带来人物形象版本及明确定妆选择。

- 修复正文、作品目录和场景规划在检查后、提交接手前被外部修改时仍可能覆盖的窗口；同一恢复事务核对原始文本，冲突拒绝写入。规划历史和接受回执的已有文件保留，空回执也不能当成不存在；保存排队后改动输入不影响原保存。不是任意第三方磁盘写入时序的绝对原子性保证。
- 人物形象支持年龄、衣装、表情、视角、时期、约束和备注，固定源图版本与人物基线。作者预览后明确选定旧版本，新编辑和新源图不自动替换定妆；回收前先明确清除选择。支持查找、分页、回收恢复、未存草稿恢复与备份后新作品身份。
- 形象版本为本地整理与选择；参考图编辑、多图AI年龄/衣装变体及真实人物视觉一致性仍在开发，未将测试用合成色块视为绘画质量验收。
- 修正知识上下文测试的活动桌面单写入边界及紧凑窗口测试入口，保留此前失败与复现证据。alpha.34公开前主动取消，保留不可变标签，不重跑。

源码资格已通过366项、实际编排/合并/窗口故障/接受中断恢复。阶段发布仍须同标签全套CI、实际安装运行/重装/卸载、公开alpha.3/31/33三条升级及精确字节清单；全部通过后工作流才公开安装EXE和三个核对文件，之后下载公开附件复算哈希。

旧alpha.33及更早版本：手改manuscript/、book.json、planning.json、规划历史或接受回执前，请关闭程序并保留独立备份，避免同时写同一作品。

未代码签名，属于阶段预览。完整106项仍26 verified、50 in-progress、30 planned。场景树、导入补全、真实模型文学/视觉质量、原生中文IME与辅助技术、大书性能、带图出版、远端发布及商店认证继续推进，稳定门禁保持关闭。
