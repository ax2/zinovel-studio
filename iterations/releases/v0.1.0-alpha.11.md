# ZiNovel Studio 0.1.0-alpha.11 — 有正文依据的认知矩阵

新增命题与秘密资料，按稳定身份组织世界记录、读者和指定人物的认知。明确区分知道、相信、怀疑、不知、遗忘和未明确；空格表示没有记录，不自动推断人物不知或认知最终状态。相似命题和相反记录不会被自动归并。

手工记录必须绑定本书已保存正文选区，保留原引文及人物/命题定义版本。正文或设定修改后显示待复核；作者重新绑定当前依据才生成新版本，旧引文仍可从历史查看。支持停用/恢复、全文依据跳转、叙述章节过滤、分页记录以及认知/新命题本机草稿的重启恢复；草稿无法落盘时阻止关闭，避免丢失输入。AI 不能自行改写作者设定的真相性质。

全书证据与矩阵查询支持逐批次取消，旧窗口的清理不会取消新的筛选。减少聚焦查询的关联读取；全量大型书查询性能仍未达到目标。修正 Windows 故障探针，按进程 ID 与创建时间核对原进程退出，查询异常不当作退出成功。

Windows x64 未签名技术预览。附件包含安装 EXE、SHA256SUMS.txt、release-manifest.json 和 runtime-inventory.json，不提供 ZIP。本标签流水线完成全套检查、安装后实际运行、重装/卸载保稿与公开 alpha.3 升级后才创建 Release。安装前关闭旧应用并备份作品，构建提交与各附件哈希见清单。

完整上架资格尚未完成。旧认知关联整理、作者指定最终状态、故事时刻推演、完整降级、图像地图、多格式出版、应用自动更新和真实云模型文学质量仍未验收。独立认知事件包含在整书备份中，正文导出不含；应用级任务与本机未保存草稿不属于整书备份。本版新增命题类型，不建议用旧版本继续编辑新书，降级需另行验证。
