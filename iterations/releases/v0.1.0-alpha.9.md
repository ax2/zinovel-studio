# ZiNovel Studio 0.1.0-alpha.9 — 独立试写实验室

新增同场景开篇试写与文风实验：独立样稿分支、视角/声音/人物行动/阻碍/读者承诺、手工编辑和并排比较、作者选版及理由、绑定原稿版本的试读反馈、历史与回收站。明确建立新章节，不覆盖既有首章；已保存的实验数据进入整书备份。

独立试写 AI 基于官方 DeepSeek Harness，只读取发送前可见的场景、当前样稿和明确选择的资料。可预估、取消、逐块审阅、手改候选和保存审阅草稿；重启后继续。接受只更新当前试写正文，版本冲突拒绝覆盖，接受中退出通过事务回执核对，不重放结果覆盖后续手改。

修复共享编辑器初始化 CRLF 可能改写旧稿的问题；新增试写本机草稿、空间不足时的关闭保护与真实重启恢复检查。保留 alpha.8 的场景看板、章纲、十二类资料及正文 AI 编辑功能。

附件为 Windows x64 NSIS 安装 EXE、SHA256SUMS.txt、release-manifest.json 和 runtime-inventory.json，不提供 ZIP。标签流水线通过全套检查、安装后实际运行、重装/卸载保稿和公开 alpha.3 升级后才发布。准确构建提交、安装文件哈希和验收清单见附件。安装前关闭旧程序并备份作品。

这是未签名技术预览，不代表稳定版或商店验收。模型测试使用官方 Harness 和本机合成服务，真实云模型文学质量尚未验收。地图/图像、全书关系与认知矩阵、多格式出版、完整工作区迁移及自动更新仍在开发；应用级任务、审阅草稿和未保存本机输入不在整书备份内。
