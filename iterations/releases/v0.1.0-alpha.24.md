# ZiNovel Studio 0.1.0-alpha.24

新增可编辑 DOCX 导出。从已保存的发布副本导出明确选定的章节，保留公开书名/作者/简介/版权与AI说明、章节顺序、真正的Word段落和标题样式。可选Letter/A4/A5、字体类别、字号、行距、边距和段落分页，生成页码和独立摘要清单；不会改写原稿或覆盖既有导出。支持的本地导出为TXT、Markdown、HTML、PDF与DOCX。

安装机无需Word、Python、Node或办公引擎。DOCX生成器随程序内置，字体/分页由打开文件的软件匹配，导出后请检查罕见字和页码。当前DOCX/PDF为纯文字，不含封面插图或自动目录，也不提供相应格式导入。

本机候选通过213项源码检查、完整源CI、139项实际安装/运行/重装/卸载保稿及公开alpha.3覆盖升级。DOCX另外由独立原生阅读器和Microsoft Word实际打开、编辑保存及逐页渲染验证，长标题/网址/罕见字三组共40页核对。公开附件须由本标签工作流重新完整构建、安装、升级及核对hash后发布，不能借用本机候选摘要。

下载ZiNovel-Studio-0.1.0-alpha.24-windows-x64-setup.exe，并核对SHA256SUMS.txt。Windows x64未签名阶段预览，升级前保留作品备份。完整106项规划、EPUB/图像出版/远端发布、真实模型文学质量、原生IME/辅助技术、大书及商店认证尚未完成。
