# ZiNovel Studio 0.1.0-alpha.32

Windows x64 阶段预览，包含可执行安装程序。本版继续使用官方 DeepSeek Harness，增加目标变化后对已有图像候选的明确复评与本地采用，减少重复生成。

- 比较原生成目标与同一人物或章节的当前版本，查看当前真实资料或章稿；这些内容只在本地核对，不自动发送给模型。原任务没有旧全文，界面如实说明。
- 作者再次确认后，只采用已收到的候选，不重新请求图像服务。目标再次改变、未处理外部改稿、跨人物/章节或缺少确认时拒绝；取消和重开清除确认，保留采用说明。
- 原请求、原目标和图片保持，独立回执记录采用时的新目标。重复采用不覆盖作者之后的编辑，备份恢复保留来源；旧版遇到新回执拒绝并保留文件。
- 补足仅写作窗口崩溃后的恢复检查：主进程保留待补存结果，重开原窗口后可只重试本地保存；普通退出和整进程中断保护继续保留。

发行工作流只有在同标签源码检查、实际安装运行/重装/卸载、公开alpha.3升级和精确字节清单全部通过后才公开安装EXE及三个核对文件。独立构建后的公开字节另外下载复算。

当前未代码签名，属于阶段预览。真实模型文学/视觉质量、原生中文IME、辅助技术、大书性能和商店认证仍待验收。参考图编辑、衣装/年龄变体、定妆选定、封面排字、章图位置、带图DOCX/PDF/EPUB及远端发布等原需求继续推进。完整106项当前26 verified、49 in-progress、31 planned，稳定发行门禁保持关闭。
