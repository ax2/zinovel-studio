# ZiNovel Studio 0.1.0-alpha.14 — 创作衔接与参考校验

空书可直接整理创意资料或开始独立试写，明确转章才建立正式正文。修复资料创建后回到正文助理仍显示旧参考列表的问题：相关界面保存会更新可选列表，已经选择并预览的发送快照仍保持冻结，需作者明确刷新。

修复原资料参考的重复失效漏检：依据正文或关联定义已过期后再次变化，即使可见文字相同，生成仍会在模型请求前拒绝旧包。纯资料和认知包统一聚合依赖证明；新预览hash会变化，历史任务继续保留原快照。资料UTF-8坏字节在快照构建及替换前拒绝，原文件保留。

完整合成创作链通过实际界面和官方Harness往返：创意、试写选版、总纲、人物、细纲、场景排章、AI候选审阅接受和真实重启；正式稿以外资料/试写快照不自动改变。这是数据和工具边界验证，不是真实云模型文学质量验收。

Windows x64未签名阶段预览。附件为安装EXE、SHA256SUMS、release-manifest、runtime-inventory，无ZIP。只有同标签完整CI、EXE安装后全套、重装/卸载保稿与公开alpha.3升级通过后才能公开。安装前备份作品并关闭旧版本。

完整上架资格未完成：1000认知事件的本机参考查询约2.5秒/矩阵约5秒，未达500ms目标；此为暖缓存单命题服务观测，不代表多定义大书或低端设备。故事时间推演、图像地图、完整出版、迁移、原生IME/辅助技术/真实模型文学质量、签名和自动更新继续开发。
