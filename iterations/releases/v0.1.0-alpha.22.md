# ZiNovel Studio 0.1.0-alpha.22

增加冻结发布副本的PDF排版导出。在“导出与发布”选择或创建一份副本后，导出格式可选PDF，并调整A4/A5、宋体/黑体类别、字号、行距、页边距和段落分页。公开书名、署名、简介、版权与AI说明来自该副本，正文只含当时明确选择和排序的章节，当前书稿和作者私有设定不会被自动加入。

排版生成封面、章节标题、页码及文档书签，保留罕见字和emoji。短段可尽量同页，长段允许跨页；实际字体由本机字体回退决定，导出后应检查字形和分页。暂为纯文字PDF，没有封面图/插图、章节页码目录或DOCX；不宣称专业印刷、PDF/UA或全部系统字体许可认证。单次内容8 MiB、输出128 MiB和90秒超时为运行保护，超限可缩小选章，不是小说结构要求。

独立隐藏排版窗口禁用脚本、Node、预加载和网络，排版不占正文写入队列。取消目录选择不创建排版窗口；失败不提交正式导出，临时文件按本次任务清理。每次建立新目录而不覆盖既有副本，manifest记录精确快照、排版选项、模板/HTML摘要、引擎版本与实际PDF摘要；本地导出不等于远端公开。

本机与标签流水线分别验收。标签必须完整通过源码、真实作者操作、独立PDF字体/Unicode/内容/章序/纸张/边界/PDFium渲染、安装后PDF及官方Harness回归、重装卸载保稿和公开alpha.3升级，再发布Windows x64安装EXE与匹配清单。Python解析工具只用于开发/CI，用户运行程序不需要Python或Node。

本版仍为未代码签名的阶段预览。目录选择结果在自动化中替换；实际原生IME、真实模型文学质量、大书性能、完整分发审核及其余产品规划继续开发。完整上架门禁保持关闭。

下载ZiNovel-Studio-0.1.0-alpha.22-windows-x64-setup.exe并核对SHA256SUMS.txt；以该标签成功CI及release-manifest.json为实际资格，不能继承alpha.21。升级前保留作品备份。
