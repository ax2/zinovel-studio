# ZiNovel Studio 0.1.0-alpha.26

本阶段加强备份与离线写作保障，并修复窄窗口展开创作参考后阅读正文被挤出屏幕的问题。Windows x64预览安装程序随本Release提供；安装不需要Node、pnpm或Python，当前未代码签名。

- 备份目的地按真实路径检查，拒绝书库根、原书、另一部作品及指向书库的目录别名。请选择书库外的独立目录；已有v1备份恢复保持兼容。
- 增加模型等待、服务报错、切换作品和完整重启后的手工保存/阅读检查；模型失败不会自动应用候选或覆盖正文。
- 阅读布局与写作状态栏样式分离。窄窗口打开创作参考后仍能进入正常阅读，发行检查同时验证实际正文行宽和屏内位置。
- 标签流水线增加安装EXE的备份恢复和离线检查，独立文档QA依赖在安装前检查；只有全套安装、重装、卸载、旧版升级及清单生成成功才公开安装包。

安装后可直接手工写作；AI生成需另配置模型服务。附件SHA256SUMS.txt用于核对本次CI安装包，完整实际验证和历史失败记录见仓库assessments/release/v0.1.0-alpha.26。

这是阶段预发布版本。增量备份、权限完整验收、EPUB、带图DOCX/PDF、远端发布及完整上架资格继续开发；本次不提升稳定版门禁。请连同独立备份保留重要原稿。
