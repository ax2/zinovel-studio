# ZiNovel Studio 0.1.0-alpha.3

Windows x64 技术预览更新，增加生成中断后的文字恢复与任务预算。完整小说平台仍在开发，尚不是稳定版或商店验收版本。

## 新增与修正

- 在正式提案生成前也会保存模型已输出的可见文字。取消/异常退出后可从任务记录查看已落盘片段，不自动重发请求或改稿。片段不是完整提案，只读保留；默认 200ms 合并写入，强杀可能丢失尚未落盘尾部。
- 模型设置新增任务步骤、章节上下文、每步输出和已回报 Token 上限，任务开始时冻结；超额阻止下一步，旧结果保留，作者可调整预算后明确重试。
- 使用官方 token-meter 启发式估算，发送前检查完整消息/系统/工具的预估输入。生成前显示作者材料预估，并明确其范围。
- 可为当前模型填写 CNY/USD 及四类 Token 单价；历史任务保留自己的价格。分别显示供应商已回报用量、自定义价格换算金额、请求预估与未知项。费用阈值在发送前检查累计已知金额和下一请求预估，未知费用阻止继续。估算不是账单硬封顶，单次真实调用可能超过预估。
- 修复展开设置时窗口超出屏幕的问题，支持滚动和窄窗保存；更新公开设置白名单回归测试。

## 安装

下载 `ZiNovel-Studio-0.1.0-alpha.3-windows-x64-setup.exe`。内含 Electron/Node 与官方 DeepSeek Harness 0.2.1-rc.2，无需预装 Node 或 pnpm。普通作品仍保存在用户应用数据目录，升级前建议整书备份；暂无应用自动升级。

未代码签名。Windows 可能显示未识别发布者；`SHA256SUMS.txt` 用于校验下载字节，不能替代发布者签名。提供完整发行清单和运行时清单，不提供 ZIP。

## 验证与边界

发行工作流必须通过源码/上游检查、单元测试、真实 Electron、官方 Harness 本机模型 fixture、安装后 EXE、重装/卸载保稿，才创建附件。安装后还会执行任务/接受事务/旧版恢复、流式强杀恢复、预算与价格 UI 验证；具体版本、SHA-256 和检查回执以附件 manifest 为准。

尚未完成真实云模型文学质量/账单核验、真实系统 IME/读屏器/低配置专项、签名/自动升级、多候选逐块差异、结构化创意/大纲/人物/世界/主支线/伏笔、地图/定妆图、EPUB/DOCX/PDF 与小说站发布等。进程强杀不等于物理断电；费用控制也无法证明供应商隐藏重试或未回报消耗的账单准确性。
