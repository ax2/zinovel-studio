# ZiNovel Studio 0.1.0-alpha.4

**已撤回的预览候选。** 发行后复核发现：接受操作中断并恢复后，新保存的审阅草稿在再次打开时可能被旧的接受前文本遮住。草稿文件仍在，但自动选择错误；请使用公开 alpha.3 或等待修复版。alpha.4 标签及证据保留，Release 撤回草稿，不重写标签。

Windows x64 技术预览，增加逐块候选审阅和可恢复审阅草稿。完整小说平台仍在开发，不是稳定版或商店验收版本。

## 改进

- 对照原文和候选的修改块，分别采用修改或保留原文；组合结果可手工调整，最后经已有事务一次写入，支持一次撤销/重做。行结束符和 Unicode 不会因差异计算被规范化；大文本有界计算，必要时明确降级为一个修改块。
- 显式保存审阅草稿，关闭或重启后从任务记录继续。草稿与模型原候选、最终接受文本分别保存；来源哈希和版本检查拒绝旧窗口覆盖新草稿，损坏文件保留并报告。未点击保存的调整仍可能丢失，界面有状态提示。
- 调整窄窗差异布局、复选框排列和深色错误提示对比度。沿用 alpha.3 的流式恢复、任务预算、自定义价格和费用预检。
- 发行增加 alpha.3 到本版的真实覆盖升级验证：旧程序实际保存合成正文/加密设置，新程序覆盖安装后核对原文件并操作新草稿功能，再验证卸载保稿。此指定路径验证不代表任意版本、架构或数据格式迁移均已验证。

## 安装与验证

下载 `ZiNovel-Studio-0.1.0-alpha.4-windows-x64-setup.exe`。内含 Electron/Node 和官方 DeepSeek Harness 0.2.1-rc.2，无需开发环境。未代码签名，Windows 可能显示未知发布者；升级前建议整书备份。附件包含 SHA-256、发行 manifest 和运行时清单，不提供 ZIP，没有应用自动更新。

当前整书备份包含作品目录的正文、历史和标记；应用级 AI 任务与审阅草稿尚不在其中，跨设备迁移这些记录仍需后续工作区备份能力。

发行工作流要求单元/源码/真实 Electron/官方 Harness fixture、安装后的完整套件、重装/卸载保稿、指定跨版本升级通过，才发布 EXE。公开包与本机包由独立构建产生，具体哈希和资格以公开 manifest 为准。

多候选并排比较、另存小说分支、结构化大纲/世界/人物/主支线/伏笔、地图/定妆图、EPUB/DOCX/PDF 和站点发布等仍待完成。真实云模型文学质量及账单、系统 IME/读屏器、低配置和签名/自动升级尚未验收；不把 fixture、进程强杀或本机测试等同真实供应商质量、物理断电或商店审核。
