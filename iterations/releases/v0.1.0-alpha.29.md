# ZiNovel Studio 0.1.0-alpha.29

本阶段修复更换模型服务时沿用旧API Key的问题，并交付当前会话脱敏诊断。建议使用旧版且需要更换模型服务的作者升级；升级前也可先在原服务地址下清除已保存Key，再输入新地址和对应Key。

- Key绑定完整规范化服务地址，包括租户路径。同一服务改模型可保留；更换服务且留空保存会清除旧密文，修改地址也会清空未保存Key输入。界面在保存前明确说明。
- 外部修改地址与绑定不符时，使用Key前拒绝，不改原设置；无版本旧加密配置兼容，损坏/未来格式保留并拒绝覆盖。继续使用OS安全存储，界面不读回Key。
- “故障诊断”保留当前会话最多200条固定元数据，不收集正文、提示词、候选、书名/ID、路径、端点、Key或原始异常。可预览、明确清空或手工导出新JSON，不自动上传，退出清空。它记录宿主返回结果，后台备份最终状态仍在对应窗口查看。
- 继承增量备份、明确选版恢复新书及其关闭保护。修复离线探针初始导航就绪等待，恢复探针继续使用精确公开字段白名单。

alpha.28标签发行失败，随后新增凭据负面复现撤销其本机资格，没有公开28或移动旧标签；失败日志和原本通过的有限机器证据分别保留。alpha.29必须独立通过全部源码、安装/重装/卸载、旧版升级及精确文件清单后才公开附件。

Windows x64预览安装不要求预装Node、pnpm或Python，当前未代码签名。完整多模型/文字图像能力、全日志审计、真实模型文学质量、原生IME/辅助技术、大书性能、自动备份策略、EPUB和带图DOCX/PDF、远端发布及完整上架资格继续推进。
