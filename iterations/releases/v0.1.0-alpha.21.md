# ZiNovel Studio 0.1.0-alpha.21

本阶段增加手工地图册。在“世界地图”中打开“年代与层级”，创建作者年代组、调整顺序，把地图加入目录，并为城市/室内子图明确选择父图及地点/区域锚点。目录支持年代组、顶层/子图筛选和分页，能打开具体地图或返回父图。各图保持独立底图、坐标和比例尺，不合并图形或推断年号顺序。

临时空年代名、未选完的锚点与循环选择可保留本机草稿，正式保存会拒绝无效关系。Ctrl+S保存当前顶层地图册；本机空间不足阻止关闭，但可完成后明确保存正式目录。未知草稿只读保留；另一份本机草稿变化不会被覆盖，过期基线须明确对照。保存后草稿清理失败时禁止重复保存，重试清理不新增修订。

外部修改按修订和原始hash检查。作者可读取磁盘目录供对照，再明确保留当前调整并采用新基线。查看历史只读，采用另建目录版本；不会回退地图图形。历史名称来自当前地图，关系/年代组/说明来自历史目录。回收/失联地图或锚点会保留引用并诊断，不按同名图猜测重接。移除目录位置不删除地图，有子图或关联年代组时须先解除关系。

已保存目录与历史包含在整书备份中，恢复到新书保留来源与关联；未保存本机草稿不在备份内。暂限每书1000节点、128年代组、32层、1MiB目录，单次最多调整40个地图引用。这些是运行保护，不是小说结构要求。窄窗可在目录和编辑表单间切换，避免同时堆放多个滚动区域。

本机候选和公开附件的资格分别记录。标签工作流必须独立通过源码、实际作者操作、安装后地图册与官方Harness回归、重装卸载保稿、公开alpha.3升级和原生图像模块/许可证检查，才公开Windows x64安装EXE与哈希清单。实际结果以该标签的成功CI及release-manifest.json为准，不能继承alpha.20资格。

仍为未代码签名的阶段预览。当前没有空间叠图、自动历史状态/故事时间推演、角色行程、AI地图册写入或图像生成；定妆、带图出版等继续开发。目录选择结果在自动化中替换，不宣称原生IME、真实手机、完整辅助技术或真实模型文学质量已验收。完整功能和稳定上架门禁尚未完成。
