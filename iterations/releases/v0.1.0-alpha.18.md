# ZiNovel Studio 0.1.0-alpha.18

本阶段增加小说原图资源库：在写作工具栏打开“图像资源”，导入本地PNG/JPEG/WebP静态图，保存用途、来源、权利说明与关联资料。原图按原始字节保留，预览遵循JPEG方向，替换与历史采用会保留旧版；支持回收恢复、冲突对照和本机草稿恢复。

稳定导入身份可在结果未确认时检查已保存记录，避免重试重复导入；损坏原图/未知元数据保留并报错，不自动重写。带图作品备份先检查512MiB恢复容量，避免产生已知超限备份。原图暂限20MiB、2000万像素、单边16384；仅支持能安全建立不可变文件的本地书库。

安装附件为Windows x64 NSIS安装EXE，未代码签名。发布流水线必须重新通过实际安装、安装后完整界面及官方Harness回归、重装/卸载保稿和公开alpha.3升级，并生成精确字节清单；另核对打包sharp原生模块加载与保留许可证SHA。具体执行结果以本标签成功的CI及release-manifest.json为准。

这仍是阶段预览。用途分类不等于选定出版封面或已拥有素材许可；图像生成、地图坐标/路线编辑、定妆选定、裁切、章节插图位置与带图出版尚未实现，完整106项需求和稳定上架资格继续推进。文件选择在自动化中替换结果，未把它算作原生对话框点击验收；原生IME、辅助技术和真实模型文学质量仍需后续验收。

请从本Release下载ZiNovel-Studio-0.1.0-alpha.18-windows-x64-setup.exe，核对SHA256SUMS.txt；release-manifest.json含实际安装、升级与图像运行时证据，runtime-inventory.json记录运行依赖。升级前保留作品备份，未保存的本机草稿不属于整书备份。
