# ZiNovel Studio 0.1.0-alpha.25

新增带图发布副本：从本书图像资源明确选择封面、章节开头/结尾插图及版本，填写替代文字、公开图注与署名，与选章一起冻结。后续替换或回收当前原图不会改写旧副本，预览显示当时的固定图像。尚未填写完整的图片表单可保存在本机，修正后才能捕获。

带图HTML包含固定PNG、目录/章序、上下章导航和夜间偏好；图片文件和文字一起进入摘要清单。发行图按原方向保留完整尺寸、去除图片元数据，原图字节不变。取消不创建导出，原稿和已生成目录不被覆盖。当前最多32处图片、单张发行PNG64MiB、去重图片总量128MiB，这些是保护限制，尚无极限负载资格。

带图副本当前支持HTML；DOCX/PDF/EPUB插图等继续开发，其他格式会明确拒绝含图副本。既有无图副本仍支持TXT、Markdown、HTML、PDF和可编辑DOCX。未实现的格式和远端发布不会被标成功。

本机225项检查、完整源码CI、第二轮143项真实安装/重装/卸载保稿和公开alpha.3升级通过。首轮地图拖动观察失败及未定因记录保留；增强探针等待选择模式并核对真实pointer事件，没有更改地图生产代码。公开EXE由本标签独立工作流再次完整构建/安装/升级和校验后发布，不继承本机候选字节。

下载ZiNovel-Studio-0.1.0-alpha.25-windows-x64-setup.exe并核对SHA256SUMS.txt。Windows x64未签名阶段预览；升级前保留作品备份。完整106项、真实中文输入法/文学质量/移动设备、大书性能、独立备份和权限等完整验收、商店认证仍在推进。此次没有将纯文字DOCX/PDF子项冒充完整格式要求，稳定版门禁保持关闭。
