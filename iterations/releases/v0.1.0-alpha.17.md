# ZiNovel Studio 0.1.0-alpha.17 — 冻结发布副本与原文保护

新增“导出与发布”：明确填写公开信息、选择并排序章节，创建可重启保留的冻结副本，逐章预览并导出 TXT、Markdown、带目录和上下章的独立 HTML。后续改稿不改变旧副本。读取捕获可取消，提交阶段等待完成；表单 Ctrl+S 不创建副本，本机草稿失败会保留输入并提示。取消目标目录选择不生成文件，导出创建新子目录并核对字节与哈希。副本进入整书备份，未创建的本机表单不进入备份。

修复旧版非法 UTF-8 原文读取后保存可能改写字节的问题。正文、书目、搜索、导出与恢复前像严格校验，损坏编码报错并保留原件；拒绝不完整 Unicode 写入。合法 BOM、CRLF、实际替换字符和生僻字按字节保留。其他编码请先使用导入预览，建议升级前另存作品副本。

保留独立阅读、创作资料、试写、全书证据与认知参考功能。资料参考刷新后保留作者已展开项，修正刷新重挂载导致观察失败的问题；Windows 验收按 PID 和创建时间核对原属进程，卸载权限不确定状态继续观察，只有实际文件和注册项消失才通过。

alpha.15 已撤回为草稿；alpha.16 标签发行两轮失败，未公开。本版本须重新通过源码、实际安装后全部功能、重装/卸载保稿、公开 alpha.3 跨版本升级与本标签 CI 才公开附件，不继承旧版资格。

Windows x64 未签名阶段预览，附件包含可执行安装 EXE、SHA256SUMS.txt、release-manifest.json 和 runtime-inventory.json，无 ZIP。快照上限暂定32 MiB；地图/插图资源、EPUB/DOCX/PDF、网站发布、自动更新、辅助技术、大书性能与完整106项需求仍在开发，尚非完整上架产品。独立 HTML 的390px为桌面模拟，不代表真实手机验收。
