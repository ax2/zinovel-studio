# ZiNovel Studio 0.1.0-alpha.31

Windows x64 阶段预览，包含可执行安装程序。以小说写作为中心，继续使用官方 DeepSeek Harness；本版增加作者控制的 AI 图像工作流，并修复 Windows 首次保存模型 Key 后异常退出可能无法再次读取的问题。

- AI 图像工作室：明确选择独立图像模型及内联响应模式，准备提示词、用途、人物或章节目标，查看预算后确认发送。准备过程不联网，不借用文字模型的 Key。
- 候选可以预览、命名并明确采用为书内资产。混合响应保留有效图片及原始位置，单张坏图不丢弃其他有效结果；全部无效也如实保留响应事实。
- 已收到但本地未保存的结果可只重试本地保存，避免重新调用付费接口。关闭窗口会保护正在进行的请求和待保存结果；异常中断后的远端未知任务不会自动重发。
- 新 Windows 凭据采用当前用户 DPAPI 封装；原 Electron 密文保持读取兼容。已经丢失旧加密材料的凭据需要重新输入，本版不能恢复丢失的 Key。
- 人物或章节在请求前后发生变化时，拒绝陈旧任务覆盖当前目标，保留结果供后续处理。

发行工作流仅在同标签源码检查、真实安装运行、重装、卸载、alpha.3 升级及精确字节清单全部通过后公开安装程序。附件包含安装 EXE、SHA256SUMS.txt、release-manifest.json 和 runtime-inventory.json。

本版未代码签名，属于阶段预览。图像协议和恢复验证使用本地受控服务及自绘图片，尚未完成真实供应商视觉质量与人物一致性验收。参考图编辑、衣装/年龄变体、定妆选定、封面排字、章图位置、带图出版及完整上架要求继续开发。基础人物/章节关联不等于这些功能已完成。原生中文 IME、辅助技术、大书性能及商店认证仍待验收。

请保留稿件和备份；完整规划 106 项目前为 26 项 verified、49 项 in-progress、31 项 planned，稳定发行门禁保持关闭。
