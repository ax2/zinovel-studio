# ZiNovel Studio 0.1.0-alpha.23

本阶段优化小说专用Windows运行包，保留官方DeepSeek Harness SDK/CLI 0.2.1-rc.2、小说工具白名单和既有全部作者功能。减少未启用的通用办公引擎、语音原生组件、调试器和部分通用桌面客户端资源；CodeMirror/React/图标库已编入工作台，改为构建依赖，避免重复分发。没有新增通用办公、语音或调试界面。

按同一打包检查时点的物理文件清单，运行文件905104365→621166433字节，约863.17→592.39 MiB，减少31.37%；本机候选安装EXE由alpha.22的222957259字节降至155322298字节。启动后归档会多一份小文件，完整目录的实际计数另记，不把这组测量当成安装耗时或内存基准。

保留上游模块代码、包清单和许可文字，官方Agent未被替换。共享资源清单随程序与源码保留，打包检查验证排除资源确实不存在、保留依赖可在应用内解析、原生图像仍实际加载；这是一份小说专用分发，不承诺运行通用DSH所有可选桌面功能。后续启用相关能力时必须重新带入并验证其资源。

本机候选和公开CI附件的实际字节分别记录。标签流水线须重新完整通过源码与作者操作、实际安装后的官方Harness、图像/地图/地图册、PDF与独立解析、重装卸载保稿及公开alpha.3升级，再发布Windows x64安装EXE与匹配摘要清单。当前只支持Windows x64预览，未签名；完整规划、真实模型文学质量、原生IME/辅助技术、全部分发认证和稳定上架门禁仍未完成。
