# 冻结副本的可编辑 DOCX

alpha.24 开发切片。只接收完整校验的 PublicationSnapshot，公开书名、作者、简介、版权和 AI 说明与选章顺序来自同一次冻结；不读取当前稿件或私有资料。TXT/MD/HTML/PDF 保持已有路线。DOCX 不是书稿主存储，也不是导入功能或远端发布。

docx 9.14.0 由 esbuild 编入桌面主程序，生成真正的 OOXML 段落、Title/Heading1、原生分页和 PAGE/NUMPAGES 页脚字段；正文可编辑，不将页面栅格伪装为文档。不执行 Markdown、HTML、脚本或网址，不带宏、远端关系或嵌入对象。公开元数据和自定义快照 ID/hash 写入文档，导出 manifest 记录布局、模板、引擎、配方与最终文件摘要。原生目录取消不生成文件，沿用 wx 临时提交和原子改名，不覆盖已有输出。宿主关闭等待导出，生成不占用书稿写队列。

纸张 Letter（默认）、A4、A5；字体宋体/黑体类别、9–18pt、1.2–2.4 行距、标准/宽边距和短段分页为受控选项。PDF 与 DOCX 共用纯选项验证，各自允许的纸张保持独立。文本换行在展示层统一，保留 TAB 与罕见 Unicode。页脚定义独立 8pt 段落样式，避免页码字段继承正文字号。长词允许换行；长标题可跨页，不静默截断。实际字体与分页由阅读器决定，不承诺 Word 与 LibreOffice 像素一致。

在创建 Word 对象前预检冻结 JSON 8 MiB、实际段落 20,000、显式换行 100,000；拒绝不适合 XML 的控制字符。输出上限 64 MiB。包含封面和章节标题的所有文本均计数。一次约 2.94 MB/10,000 段落合成观察：生成约 173ms，并发同书写稿约 161ms；这不是 P95 或大书资格，不据此增加后台 worker 或宣称所有规模流畅。

独立验证用 python-docx/标准库 ZIP 和 XML，不借用生产 docx 库断言自身；检查 CRC、可编辑全文、原生样式、纸张/字号/行距、选章顺序、罕见字计数和无外部关系。开发专用 DeepSeek LibreOffice Kit 0.1.5 原生引擎将实际作者界面产物转 PDF，再用空间文字提取、字形边界与 PDFium 逐页渲染检查。跨页文字剔除页脚前，必须验证页脚区域恰好为该页/总页数，不能删除正文中的数字。所有排版页面生成，代表图和总览实际查看。

Microsoft Word 另开自有合成副本做打开、编辑、保存和前后 PDF 输出。探针遇已有 Word 进程即拒绝，不关闭用户文档，按窗口 PID/创建时间确认自有进程并等待退出。改存 Word 文件可能含 Office 用户元数据，不提交原始改存副本。Word 不是应用运行或 CI 依赖。文档技能通用渲染脚本因本机无 soffice.exe 未通过，该失败独立保留；不把本路线称为该脚本通过。

许可证采集脚本保留 docx 的 17 个打包依赖组件原始许可及摘要。hash.js 上游仅在 README 内提供 MIT 授权，因此保留原始 README。打包验证逐文件核对，产品不带开发阅读器引擎。此切片不代表所有上游依赖或字体的完整法律/商店审核。
