# Windows 覆盖升级资格

下一次预览增加真实旧版安装 → 写作与设置 → 新版覆盖安装 → 读取原稿与旧任务 → 新功能草稿保存 → 卸载保稿的顺序验证。只操作测试自行创建的安装目录；生产 GUID 已有任何安装时拒绝运行，不能覆盖用户已有安装。

旧包固定为已公开的 v0.1.0-alpha.3，校验 manifest 里的版本、名称、SHA-256 后才执行。CI 下载公开附件；本机可使用已验证的本机构建与对应本机 manifest，报告分别记录两者哈希，不能冒充相同产物。新包同样记录精确 SHA-256，升级后实际运行安装 EXE 并检查内含版本。

应用使用独立合成数据目录。验证旧版实际保存正文、系统加密设置/预算、历史任务在升级后保留；比较整份 library/tasks/settings 文件字节，升级后在新界面读取并保存审阅草稿。卸载后保留稿件。运行应用时 PATH 仅含 System32，不依赖开发 Node/pnpm。

此历史切片只证明指定两版之间、同一 Windows 用户、同一架构的静默覆盖升级。不代表所有向导点击、降级、跨架构/跨设备、物理断电或完整格式迁移矩阵。该阶段涉及的旧稿件/任务schema为1；后续新格式必须单独增加验证。
