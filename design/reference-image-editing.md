# 固定参考图编辑

alpha.40接通参考编辑，协议依据见[官方编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)与[协议复评](../assessments/stage-006/reference-edit-adapter-reassessment.md)。普通文生图不等于支持编辑；作者新建openai-images-edits独立配置并确认响应方式，不能复用文字或原图像协议的凭据。

作者选择同书正式资源的固定ID/修订/hash，宿主读取原图并复核，方向纠正、移除元数据、最长边1536且实际编码不超过4MiB。衍生PNG作为不可变blob保存，任务准备不新增正式素材。schema3任务冻结原资源、原blob、衍生blob与算法，仍保留原profile/预算/用途。任务创建和发送意图都核对原资源，提交前以只读前像保护资源元数据；原图不写回。外部程序任意时刻写磁盘仍不属于跨进程原子性保证。

发送使用已经保存的衍生字节，先核对当前原资源及衍生指纹，不因重启或改图重新推导输入。传输真实解码后构造JSON images data URL；外部URL/路径、未选参考、错误协议拒绝，失效目标或参考在发送意图之前拒绝。图像任务、候选、预算、只发送一次、取消、未知远端与本地补存均复用既有协调器。参考输入可能计费，手填每图单价不是账单保证。

作者在右侧查看真正要发的PNG、目标服务和用途，明确确认后才发送。图像返回只进私有候选，明确采用才新增正式资源；不替换原资源或已选人物形象。schema3允许原有目标复评，复评不能降成schema2。旧v1/v2生成记录和原hash保持；v3必须有严格参考记录。恢复副本可查看原任务及输入图，不能接续原请求。

本地草稿选择参考后使用schema2，保存固定资源指针而不是跟随当前版本；未选择参考的旧schema1不自动升级。旧/未知格式原样保留。资源检索分页，缓存版本已失效时显示旧指针，作者明确重新选择才更新。读取预览失败不能确认发送。

基础419项、参考任务九组、真实Electron五组（包括已发送后实际强退）、原有图像与模型UI回归见[源码证据](../assessments/stage-006/reference-edit-runtime/README.md)。测试只用自行合成色块和受控HTTP，不能证明真实供应商支持、人物一致性、视觉质量或完整ART需求完成。安装、最近公开版本升级及独立发行另行执行，40资格false。
