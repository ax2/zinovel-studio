# 交互与信息架构

## 主要入口

书架：最近打开、全部作品、系列、归档、导入；卡片显示实际正文字数、正式/草稿章数、最近编辑、审读缺口。计划目标与已写进度分开展示。

书内导航：写作、规划、世界、人物、故事线、地图、素材、审读、发布。搜索可以从实体跳至正文出处。工作台记住每本书的面板、光标、缩放与阅读位置。

```text
┌ 书名 / 本卷 / 当前章              保存状态     阅读  发布 ┐
│ 卷章树       │ 第十二章 ……                     │ 参考/AI │
│ 正式/草稿标记 │                                 │ 当前人物│
│ 场景列表      │        手工编辑正文               │ 当前地点│
│ 拖拽及搜索    │                                 │ 相关伏笔│
│              │ 选区 → 润色 扩写 缩写 更多        │ 上下文  │
├──────────────┴─────────────────────────────────┴─────────┤
│ 正文字数 / 目标(可隐藏)         本地已保存 / AI 任务状态    │
└──────────────────────────────────────────────────────────┘
```

这是文字线框设计，不是已渲染界面截图。

## 局部修改完整流程

选中段落 → 操作类型和要求 → 可查看发送范围/人物/文风/锁定事实 → 生成候选 → 原文/候选差异 → 逐块接受、另存版本、拒绝 → 一次撤销可恢复。

默认把选区、必要邻接段、相关设定送模型，不发送整本。扩写可设目标长度但显示实际长度；超长输出截断时显示“候选未完成”，不能标完成。模型不可用则保留原文与需求，可稍后重试。

生成期间选区高亮与光标焦点分离，用户可继续编辑。AI 结果抵达时若基线已变，显示冲突原因和重生成入口；不强行抢焦点，不在 IME composition 期间改内容。候选关闭后可从任务历史找回。

## 规划、人物与伏笔

规划页面用树/表/看板共享同一结构数据，切换不复制计划。场景卡显示人物目标、对抗、信息变化和关联线索。拖拽跨卷显示被影响的时间线、伏笔与发布章号。

人物卡正文说明与结构字段并列；关系图点击边看事件证据。复杂图表要有等效表格可检索，不把关键信息仅放颜色上。

伏笔表列计划/已埋/强化/回收/失效，实际出处点一下跳到段落。到期提示是作者提醒，可推迟、弃用或重新设计，不能要求每个悬念机械按固定章数下沉。

## 阅读与发布

阅读模式默认只展示正式阅读内容，作者信息侧栏按需打开。盲读可隐藏总纲及结局。发布面板固定显示目标、章节范围、版本、缺图、未审提示、与线上差异；预览/生成草稿/正式发布用不同动作和结果状态。

## 可访问性与布局验收目标

- 桌面 1440×900 和 1280×800，Windows 125%/150% 缩放，浅/深主题；中文长标题不得遮挡保存状态。
- 窄窗 800×600 单面板切换；阅读预览 390×844，无横向溢出，图片适配。不是移动编辑客户端交付承诺。
- 键盘可达全部核心操作，清楚的焦点、Esc 返回、读屏标签；图形有列表替代。快捷键可改，避免与系统/输入法抢键。
- 选区工具条不遮住所选文字，差异同时用文本标记和颜色。普通正文对比目标 4.5:1，放大 200% 仍可完成保存和接受候选。
- 渲染 screenshot 必须来自实际程序，保留视口、主题、缩放与检查结论。Stage-000 无真实 UI 截图。
