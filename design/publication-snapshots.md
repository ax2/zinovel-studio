# 下一出版切片评估：冻结快照与可独立阅读的产物

状态：生成层已合入 alpha.16，主机持久捕获与保存入口待实施，不提升任何 PUB 功能为 verified。alpha.15 已撤回为草稿。

依据现有代码：book.export 先 exportSnapshot 全书，再选择 Markdown 文件并直接 writeFile；exportSnapshot 持有共享队列一次读全书，没有持久发布快照。alpha.16 编码保护修复后读取已使用 fatal UTF-8 解码，非法字节不会被宽松解码后导出。现有阅读预览逐章读取当前磁盘，明确不提供出版冻结语义。不能把它直接当作已授权发布源，也不能因菜单存在就把 PUB-01 全部验收。

## 保持的完整需求

PUB-01 文本的章节选择、顺序、编码、首尾核验；PUB-02 EPUB 的封面/插图/目录和阅读器；PUB-03 DOCX/PDF 的中文、字体与真实分页；PUB-04 完整 HTML 目录、导航和移动阅读；PUB-05 快照与目标/范围/hash；PUB-06 各站点适配；PUB-07 投稿包；PUB-08 回执和回滚均保留。图像需要 Stage-006 资源版本与权利信息，不能用文字占位代表图像功能完成。Stage-005 的盲审/长篇性能及 Stage-004 余项继续推进。

## 可复用的冻结层

作者明确选择作品、有效章节、状态范围与顺序，配置署名、简介、版权和 AI 辅助说明。先核对待保存编辑；错误不得继续。宿主投影只有明确选择的书目/正文/公开资源，不把作者资料、未来设定、私有批注、任务或凭据加入快照。题名不是路径，内部目录使用 UUID。

快照需持久保存 schema、ID、源书ID/修订、每章ID/题名/顺序/卷/正文hash、公开元数据与资源hash/权利说明。canonical hash 不含创建时间等非内容字段。源正文严格 UTF-8，坏字节拒绝且保留原件。目录失联、重复/跨书ID和坏资源不导出半本。快照正文为独立复制字节，不使用可随原稿改变的硬链接。

采用共享内核的分批读取与可取消任务，避免每次预览都在队列里一次读千章。捕获后重验目录基线及所选正文/资源hash；发生改动明确要求重新冻结，不暗中替换内容。不宣称两次读取构成跨进程文件系统全局冻结。已落盘快照再做完整hash核对，之后所有格式与预览只读该快照，原稿再变化不影响它。中断日志/临时目录仅处理本任务拥有的路径，损坏快照保留诊断，不能通过“重试”静默覆盖。

## 本地导出与发布授权

预览展示确切快照、范围、目标与缺失资源。保存本地导出由作者选择目标；远端草稿、正式公开和投稿分别授权，不能沿用本地导出的授权。目标选择后再次核对快照身份，取消不创建最终产物。

本地输出先在目标同级写独占临时目录，校验全部清单后原子切换到本次唯一最终目录；既有目标文件不得先截断，不清空目录，不覆盖其他作品。生成的 manifest 记录 exported 状态及内容清单，不称 published。远端之后按 design/publishing.md 的 unknown、幂等、查询回执和安全回滚实现。

## 独立 HTML 实作约束

目录页与逐章页面、上一章/下一章、卷章导航、字体/行距/主题和窄屏阅读；不把全书所有段落一次塞入 DOM。章节文件使用已校验ID，正文/题名/属性全部转义，纯正文中的 HTML 不执行。内容链接不得成为任意脚本或外部请求；脚本与样式由固定模板提供，核心导航在关闭脚本时仍可用。资源跟随冻结版本，缺图与权利未确认明确拦截或由作者选择不含该图，不能偷换资源。

本机进度按导出快照与章hash隔离；不能借用工作台原稿或另一导出的书签。打开独立目录不依赖 Node、工作台或作者账户，不读取本机工作台数据。可在本地浏览器打开不等于公开发布或真实移动设备验收。

## 必须取得的证据

存储：坏字节/目录变动/跨书/重复章拒绝，捕获中外部编辑可见，原文和既有目标逐字节不变；重启恢复只处理自己的任务；源改稿后已冻结产物完全不变；明确排除的章节与作者秘密不出现在任何文件。

界面：作者选范围、冻结、查看首中末章、取消、保存到中文空格目录、真实退出/重启、已存在目标冲突；状态和错误可通过键盘到达。真实打开产物，检查标题、首尾段、章序、目录/上下章、长题名、中文/罕字/emoji、深浅主题、窄屏和零网络请求。千章基准要测构建/打开/内存/编辑阻塞并记录机器与视口，不能只量 manifest 生成时间。

格式：TXT/MD 内容核验；EPUBCheck 和真实阅读器；DOCX 真正打开；PDF 首中末页渲染及字体；HTML 真正打开导出目录。每种格式独立资格，不以某一格式通过代替全部出版能力。
