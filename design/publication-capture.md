# 持久出版快照的宿主实现计划

状态：下一切片设计，尚未实现，不属于 alpha.16 已交付能力。生成格式层见 publication-snapshots.md。先完成 alpha.16 安装与发行资格，再修改运行代码。

## 来源与保存

出版目录由共享存储内核读取并校验作品身份、有效章节、分卷和保存版本，返回独立目录基线 hash。作者明确选择章节与顺序；公开书名、署名、简介、版权、AI 辅助说明使用现有严格白名单。IPC 只接受身份与选择，不接受渲染器提交的正文作为可信来源。

分批读取严格 UTF-8 正文，按批释放共享队列，允许取消；记录每章实际正文 hash、目录保存 hash、版本与卷章题名。拒绝重复、删除、失联或跨书章节。外部稿件与保存 hash 不同必须在快照预览显著提示，冻结保留实际捕获文本及两个 hash，不能自动改写或“修复”原文。导出只能来自作者实际查看的快照，不能再临时读取最新原稿。

捕获后分批重新核对所选文件字节与目录基线，发现变化则停止，要求重新冻结。最后短队列内再次核对目录与取消状态，再通过内核事务保存完整快照。不能在共享 exclusive 中调用 ReaderStore.catalog 等再次排队的入口；复用同步目录投影。预计为内核事务增加可选 before 前像条件，让新快照要求目标不存在，避免覆盖已有记录。UUID、路径和完整 hash 均检查；快照加载仍重建白名单与 hash。

两次读取不提供跨进程文件系统全局冻结保证。应用内改稿通过目录 CAS 检出；外部文件以捕获/重验的实际字节为准，快照保存后独立于原稿。需要实际千章捕获、提交耗时、内存与编辑响应数据，才能确定批量大小和公开容量限制，不先声称大书性能达标。

## 取消与重启

宿主按窗口/作品维护独立捕获身份与 AbortController，不使用 AI 任务身份或模型请求。读批与重验可取消，提交开始后不可取消：取消请求必须返回正在提交，不能在快照已落盘后仍向作者宣称取消成功。提交前取消不创建最终快照，事务中断按现有恢复规则处理；重启只读取已完成快照，不自动重放捕获或导出。

快照列表须逐项报告损坏/未知版本，保留原文件，不能因一项损坏而伪装为空列表或自动覆盖。新捕获有新身份，不改旧快照。作者后改正文、目录、署名不影响旧产物。

## 备份与来源身份

现有备份复制作品内原始文件，因此作品内快照应纳入备份。恢复会生成新作品 ID，不能重写快照内部原书 ID 或内容 hash 来假装新原稿。计划在恢复书目的非冻结字段记录原书 ID 来源链；快照加载仅允许当前作品或明确恢复来源链的原书身份，界面展示历史来源。连续两次备份恢复需验证来源链保留；旧备份、未知/损坏链及任意跨书快照复制均须分别测试，未实现前不宣称出版快照可恢复。

## 导出边界与验收

作者选择已保存快照及 TXT/Markdown/HTML，预览首中末章和顺序，再选择本地目标目录。保存对话框取消不创建产物；返回后重新核对快照 ID/hash，不能把作者资料、任务、未来设定或凭据带入输出。唯一输出目录与同级任务暂存目录均只属于本次导出；已有目标必须保留。写入后逐字节核对清单，完成后才记录 exported；此状态不能称 published。

真实桌面须完成选择范围/调整顺序/冻结/重启查看/取消/中文空格路径保存/已有目标冲突/原稿后改不影响导出/坏 UTF-8 与损坏快照拒绝等流程，原生对话框交互与仅替换选择结果的宿主负向测试分别报告。独立浏览器再次核对目录、上下章、中文/罕字/emoji、主题、窄屏和零外部请求。每种格式分别取得资格；EPUB、DOCX/PDF、插图资源与远端站点后续独立推进，保留全部 PUB 需求。
