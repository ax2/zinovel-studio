# 图像任务账本与本地恢复

alpha.31源码切片；尚未开放图像profile、宿主IPC、作者生成界面或采用功能。不属于已公开alpha.30安装包。

每部书的`.zinovel/image-tasks/<UUID>.json`由该书唯一BookStorageKernel保存；NovelStore注入现有assets/materials及同一内核，不启动第二写入器。整书备份包含提示词、模型身份、用途、目标修订及接收回执；这些属于私人创作数据。记录不含Key、密文或服务地址。最多1000条任务、单记录256KiB，读取严格UTF8并以原字节hash做CAS，异常/未来格式保留原文件。

任务创建冻结request、手填预算、所选profile修订与目标版本，稳定创建ID保证重复确认不会再创建或重发。发送前重新检查人物/章节版本并提交send-intent与attemptId。磁盘意图只能证明请求可能发出；重启显示远端未知，不声称已经成功发送或未发送，不能自动重试。同进程只有持有该发送身份的调用者能接收返回或保存确定结果。

接收时先复制有界字节、用量和标志，再等待解码与写队列；既有两个解码槽支持候选等待，普通超额预览仍拒绝。解码在书锁外；锁内先写receive-intent与每张原图hash、元信息、预留资产ID及总responseHash，再写不可变共享blob，最后写received。此时没有assets/items记录，不会改变可见资源、封面、定妆或正文。目标发送后被作者修改仍保留返回候选，实际采用须另做当前目标核对。

receive-intent恢复分两种：缺图/坏图保持未完成与原记录，可用完全匹配回执的原字节继续本地保存；所有图已落盘则校验hash和真实解码后纯本地转为received。两种路径不调用网络。原字节重试沿用候选ID/usage/responseHash，不允许换一张图伪造补存。逻辑放弃保留发送事实、接收回执和blob，不当作计费撤销。恢复副本保留来源链，不能接续原任务发送。

后续采用需持久化作者确认的资产输入与预留ID，通过现有AssetStore稳定创建身份导入，再按资产事实完成任务；跨步骤崩溃要可核对且不能重复资源。不能在exclusive内调用会再次exclusive的公开import。启用生成之前还须实现有界活跃任务/候选内存、关闭保护、明确适配选项、当前profile授权、作者候选界面及安装验证。参考图编辑、人物变体、地图底图、封面与章图出版仍单独验收，不因账本完成缩减需求。
