# 小说参考图编辑与形象变体：34之后的接入设计

状态：2026-10-25，仅方案，未进入alpha.34应用。34已有离线形象版本与明确选定；参考图服务、AI变体和真实视觉一致性仍未交付，ART-01/02保持in-progress。先完成34独立发行，再实施并另做安装验收。

## 接口核对与方案调整

2026-10-25核对[官方图像编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)：JSON `/images/edits` 接受 `images[].image_url` 数据URL。这个结论只涉及该官方接口，不证明任意兼容服务支持编辑。官方文档区分模型的可用参数；[图像生成指南](https://developers.openai.com/api/docs/guides/image-generation)说明编辑费用涉及输入图像，不能直接套仅输出图片的估价。由此决定：明确能力配置、专用编辑适配器、输入图预览和独立费用说明；不根据模型名称自动开启，也不复制固定旧模型默认值或通用input_fidelity字段。

现有model-profiles是schema1，imageOptions严格只支持responseMode。初步选择单独保存有版本的编辑能力声明，绑定具体profile ID/revision及服务/模型摘要，并复用现有配置写锁；不往旧schema1静默塞新字段。旧版可忽略独立能力文件但保留原件，profile被旧版修改后绑定失效，需再次明确确认。若实际实现证明sidecar不能保持一致，则改用显式schema2迁移，完整保留原配置/密文并实际验证降级保护；不为省测试而选脆弱兼容方式。

## 作者流程

从人物已选定妆或同书明确选择的固定资产版本开始，指定年龄/衣装/表情/视角/时期与一致性约束。先本地预览“将发送的参考图”及提示、服务/模型和输入数量，再明确发送一次。首次生成、采用候选、保存形象和设为当前定妆仍是分别的作者操作；生成不会改变已有定妆，不能把提示词中“保持一致”当作视觉质量验收。原始图像与来源保持，只生成受约束衍生输入，不自动发送整书资料或其他人物图。

第一批只做同书固定参考图的JSON内联编辑协议；不接受renderer传任意文件路径、远程URL或Files API ID，不加蒙版、远程文件上传、复杂图层等未经验证入口。拒绝不支持此能力的profile；普通图片生成选择不等于编辑能力确认。模型输入参数保持最小，具体供应商或模型特有选项另行验证。

## 输入、账本与存储

沿用唯一BookStorageKernel、已有不可变图像blob及固定资产/人物基线。建议上限4张参考图，每张衍生PNG最长边2048、最多5MiB，完整JSON请求另设硬上限；这些是初始约束，必须以实际内存、请求和安装版数据确认后再定，不是性能承诺。

宿主读取并验证同书固定资产原图，原生解码、按方向处理、缩放和移除元数据，保留原件，预览实际将发送的衍生图。衍生图需create-only持久化并校验后，文本事务保存其来源资产/原图hash、衍生hash/尺寸、人物目标、提示、配置能力修订和预算；不把图片base64塞进文本事务、不存Key。原图被改动、回收、链接或不可读时拒绝陈旧请求，保留作者草稿。

任务增加明确的编辑请求格式/operation及参考来源，不改变已有v1生成、v2目标复评的创建hash。旧程序遇新格式逐项报不可读并保留，不自动删除；新程序须读旧格式。准备、发送意图、已收到响应、部分坏图、本地补存失败、取消和远端未知继续有独立回执；只有明确用户发送后才发HTTP，网络失败和崩溃不得自动重发。输出仍走现有候选采用/显式复评，所有用途和目标限制继续生效。

派生输入位于书内独立目录，进入整书备份并验证恢复来源；不会自动成为作者资源或出版资源。解码使用现有有界槽位，不能新建另一个活动写入内核，预览慢解码期间释放书队列并在返回/发送前再次核对基线。新能力声明和profile更新必须遵守同一配置锁及冻结版本，不嵌套拿锁。

## 费用、验证与发行

先区分输出图估价与完整编辑请求成本。参考图输入可能额外计费，未知价格不能显示为零或保证总价；按服务支持保存明确的计价/未知范围，限制图片数和单次发送，取消不承诺免费。沿用旧Key服务地址绑定及路由修订校验，无自动切换服务、重定向、远图抓取或重试。

验收至少覆盖：原图不变且衍生元数据移除、跨书/陈旧/链接/损坏图、能力未确认/被修改、真实HTTP内容和只发送已预览输入、非编辑端点拒绝、混合/全坏响应与本地补存、窗口/整个进程中断、一次请求原则、已有定妆不变、备份至新书、旧程序保护、新旧公开版安装升级，以及浅/深窄窗作者流程。使用合成资料和Key；受控HTTP能验证协议和恢复，不能证明真实供应商的视觉一致性。真实艺术/文学效果、可访问性和原生IME仍需相应范围的实际验收。

34发行期间只保留此设计，不新增空壳按钮、功能verified状态或虚构服务质量结论。
